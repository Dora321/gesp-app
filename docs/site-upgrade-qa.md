# 全站视觉升级与流程复测

更新：2026-10-24。最终本地验收通过；部署结果以对应提交的 GitHub Actions 为准。

## 完成范围

- 将首页的学习线路设计语言应用于导航、页脚、题库、考试、C++ / Python 课件外壳、科创目录、博物馆和全局工具；E-Kart 首页改为工程课程入口，专属样式随路由加载。
- 手机考试顶部栏适配 320px；题号抽屉关闭时隐藏，短屏可滚动；为底部操作留出空间，避免标注工具遮挡。
- 交卷与成绩窗口支持焦点循环、Escape 关闭、焦点归还和短屏滚动；提高成绩统计文字与已交卷题号的对比度。
- 修复最后一题的“检查交卷”和“查看结果”无响应；所有“返回题库”按钮明确导航到题库。
- 跨页面进入首页目录通过 URL 锚点定位，移除固定延时，并验证首页模块慢加载时的行为。
- 修复 768px 题库筛选栏横向溢出、E-Kart 二级导航遮挡手机主导航，以及部分课程代码滚动区无法键盘聚焦的问题。
- 科创课件外框提高深色区域文字对比度；弹窗、手机菜单打开时隐藏浮动标注与返回顶部工具。
- 编程题参考代码显式包含 cassert，保证本机工具链可编译；更新开发依赖 Zod，恢复高危依赖审计门槛。

迁移边界见 [设计语言](site-design-language.md#9-迁移范围)。独立 HTML 课件、3D 应用和各课自定义教学游戏保留内容自身配色，不属于本轮站点外壳迁移范围。

## 重跑

运行 npm run lint、npm test、npm run check、npm run build、npm run check:prerender、npm run check:bundle、npm run smoke、npm run check:a11y、npm run visual。

若复用服务，按脚本设置 SMOKE_BASE_URL、A11Y_BASE_URL、VISUAL_BASE_URL；生产预览地址须包含 /gesp-app 基路径。
