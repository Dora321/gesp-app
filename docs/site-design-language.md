# 魔丸聚集地 · 站点设计语言「学习线路图」

> 适用范围：全站。首页（`/`）已按本规范落地；其他页面按第 9 节逐步迁移。
> 实现文件：`src/styles/design-tokens.css`（token 与基础元件）、`src/styles/site-chrome.css`（导航/页脚变体）、`src/home.css`（首页）。

---

## 1. 设计判断

**把整个网站当成一张学习线路图。** 每个学习体系是一条线，每一级、每一课是一站，真题题库是换乘站。

这个站要回答的问题始终是「我该从哪里开始、学完去哪一站」。地铁导视是公共设计里最成熟的寻路系统：彩色线路、编号、站名、换乘——孩子一看就懂，老师和家长觉得清楚、可信。它天然有颜色，但颜色都有含义；它天然典雅，靠的是网格、细线和排印，而不是装饰。

配色来自站标：**藏青**（墨色）、**朱橙**、**芥黄**，外加一条松绿。

### 明确不做

| 不做 | 原因 |
| --- | --- |
| 紫蓝渐变、霓虹、玻璃拟态、大投影 | 常见 SaaS / AI 模板味，与教育内容无关 |
| 倾斜卡片、浮动小标签、轨道虚线圈 | 只为「显得热闹」，不传递信息 |
| 四张等宽彩色卡并排 | 信息结构不同的内容被强行做成一样 |
| 装饰性英文小标签（`FIND YOUR PATH` 之类） | 读者是中文用户，英文只当花纹 |
| 假数据、假运行器、假「在线调试」 | 站内没有在线执行代码的能力，演示要如实标注 |
| 套路口号（「开启无限可能」「赋能」） | 写清楚有什么、给谁、怎么用 |
| 日式极简纸墨（大留白 + 宋体 + 单一墨色） | 用户已否定；本语言要有色彩、有信息密度 |

## 2. 颜色

全部以 CSS 变量提供，前缀 `--mw-`（魔丸）。对比度按 WCAG 2.x 相对亮度公式计算。

### 2.1 基础色

| Token | 值 | 用途 | 对比度 |
| --- | --- | --- | --- |
| `--mw-ink` | `#23283d` | 正文、标题、主按钮底（站标的藏青） | 白底 14.5:1 |
| `--mw-ink-2` | `#4a4f63` | 次要正文、说明 | 白底 8.1:1，canvas 7.4:1 |
| `--mw-ink-3` | `#676b7b` | 注释、元信息、图例 | 白底 5.3:1，canvas 4.9:1 |
| `--mw-canvas` | `#f7f5f0` | 页面底色（暖白，不是纸色） | — |
| `--mw-surface` | `#ffffff` | 面板、卡片 | — |
| `--mw-surface-sunk` | `#efebe2` | 次按钮悬停、空格子 | ink-3 在其上仅 4.46:1，**不要放小号 ink-3 文字** |
| `--mw-rule` / `--mw-rule-strong` | `#e2ddd2` / `#c9c2b3` | 分隔细线 / 控件描边 | — |

### 2.2 线路色（归属）

每条线有三档：`line` 画轨道、圆点、色条和图标（非文字，对白底 ≥ 3:1）；`text` 用于同色系文字和白字底（≥ 4.5:1）；`tint` 只做大面积浅底。

| 线路 | line | text | tint | 说明 |
| --- | --- | --- | --- | --- |
| C++ 线 `--mw-line-cpp*` | `#dd5a2e`（3.8:1） | `#b8441e`（5.4:1） | `#fbebe3` | GESP 一至八级，站标朱橙 |
| Python 线 `--mw-line-python*` | `#1f8a6d`（4.3:1） | `#14735c`（5.8:1） | `#e4f2ec` | 入门段 + 项目段 |
| 科创线 `--mw-line-maker*` | `#b97f0a`（3.4:1） | `#875b00`（6.0:1） | `#fbf1d8` | 电与磁 → ESP32 → 竞赛；线路标用芥黄底墨字（8.7:1） |
| 题库 `--mw-line-bank*` | = ink | = ink | `#ebe8f0` | 换乘站用墨色，不再加第四种彩色 |

用法：给容器加 `mw-line-cpp` / `mw-line-python` / `mw-line-maker` / `mw-line-bank`，内部元件统一读 `--mw-line`、`--mw-line-ink`、`--mw-line-wash`，不在组件里写死色值。

### 2.3 语义色（状态）

| Token | 值 | 浅底 | 用于 |
| --- | --- | --- | --- |
| `--mw-ok` | `#1d7342`（5.9:1） | `--mw-ok-tint` | 答对、已过关 |
| `--mw-err` | `#b3261e`（6.5:1） | `--mw-err-tint` | 答错、失败 |
| `--mw-warn` | `#875b00`（6.0:1） | `--mw-warn-tint` | 建议复习、待核验、风险提示 |
| `--mw-info` | `#2d4c8c` | `--mw-info-tint` | 学习中、一般提示 |

### 2.4 深色面

`--mw-night`（= ink）、`--mw-night-2`、`--mw-night-rule`；文字 `--mw-on-night`（主）、`--mw-on-night-2`（次，7.7:1）、`--mw-on-night-accent`（芥黄，8.7:1）。用于题库换乘大厅、代码块、页脚。**一页最多两块深色**（首页是题库带 + 页脚）。

### 2.5 颜色规则

1. **线路色表示「属于哪条线」，语义色表示「对不对、到没到」，两者不混用。** 对错反馈不用线路色；线路标不用语义色。
2. 线路色的 `line` 档不写小字；文字用 `text` 档或墨色。
3. 状态永远是「图标或文字 + 颜色」，不能只靠颜色（例：课时编号圈旁始终写「已过关 / 学习中 / 建议复习」）。
4. 一个区块里通常只出现一条线路色加墨色。多条线同时出现只在两个地方：首屏线路图、页脚色带。
5. 图表遵守同样规则：直接标注数值、图例与文字说明齐全，必要时加纹理（核验进度条里「待核验」用斜纹）。

## 3. 中文排印

### 3.1 字体（全部系统字体，不加载外部字体）

| Token | 字体栈 | 用于 |
| --- | --- | --- |
| `--mw-font-sans` | PingFang SC → HarmonyOS Sans SC → MiSans → 微软雅黑 → Noto Sans SC → 思源黑体 | 全部中文 |
| `--mw-font-figure` | Bahnschrift（Windows）→ DIN Alternate（苹果）→ Roboto Condensed → 正文字体 | 数字、站号、线路标（导视字体，等宽数字） |
| `--mw-font-code` | Cascadia Code → JetBrains Mono → Consolas → SF Mono → Menlo | 代码、变量表 |

不用宋体做标题：Windows 默认只有 SimSun，大字号粗体效果差，也容易滑向「纸墨风」。

### 3.2 字号层级

| Token | 值 | 行高 | 用于 |
| --- | --- | --- | --- |
| `--mw-text-display` | 32 → 54px（clamp） | 1.22 | 页面主标题，一页一个，最多两行 |
| `--mw-text-h2` | 26 → 36px | 1.35 | 区块标题 |
| `--mw-text-h3` | 20px | 1.4 | 卡片/行标题 |
| `--mw-text-lead` | 17px | 1.8 | 导语 |
| `--mw-text-body` | 15px | 1.8 | 正文 |
| `--mw-text-small` | 13px | 1.7–1.75 | 说明、按钮小号 |
| `--mw-text-caption` | 12px | 1.6 | 图例、元信息。**中文最小字号，不再用 8–10px** |

### 3.3 规则

- 中英文、中文与数字之间加半角空格：`GESP C++ 一级`、`128 节互动课`。范围用 en dash：`2023–2026`。
- 全角标点；标题不加句号。
- 中文不用负字距；标题 `letter-spacing: 0.01–0.02em`，小标题 `0.06–0.08em`。
- 标题 `text-wrap: balance`，段落 `text-wrap: pretty`，正文每行约 30–40 字（`max-width: 34–42em`）。
- 字重只用三档：400 正文、600–700 强调与按钮、800 标题。
- **JSX 注意**：JSX 会把行尾换行变成一个空格。中文句子只在本来就有空格的地方（英文词前后）换行，或整句写在一行，否则会出现「项目课、 电与磁」这样的多余空格。

### 3.4 文案语气

- 先说事实：有什么、给谁、学完能做什么、数据存在哪。数字全部从目录或 `paperStats` 读取，不手写。
- 不夸大：没有的能力不演示（例：推演示例写明「步骤是事先算好的」）。
- 小标题用中文说明（`学习路径`、`真题题库 · C++ 线终点站`），不写装饰英文。

## 4. 布局与留白

- 内容宽度 `--mw-container: 1200px`，两侧 `--mw-gutter: clamp(20px, 4vw, 40px)`。
- 间距只用 4px 基准阶梯：`--mw-space-1…9` = 4, 8, 12, 16, 24, 32, 48, 64, 96。
- 区块上下 `--mw-section-y: clamp(56px, …, 104px)`；区块之间用底色交替（canvas / surface / night）加 1px 细线，不用阴影分层。
- 桌面不是「把卡片拉大」：按信息结构选版式——
  - 并列且同构的选项 → **表格式行**（学习路径、题库入口、工具列表），左侧 4px 色轨；
  - 有主次的内容 → **不等宽网格**（项目课 1 大 2 小，首屏 5:7，题库 7:5）；
  - 大量同类条目 → **时刻表网格**（课段 4×2、课时自动填充）。
- 手机（≤ 639px）先保证首屏短：标题、导语、两个按钮；第二屏就是学习路径。

## 5. 形与控件

### 5.1 形

- 圆角只有三档：`--mw-radius-s` 3px（标签、线路标）、`--mw-radius-m` 6px（面板、按钮、卡片）、`--mw-radius-pill`（只给站点圆点和编号圈）。
- 不用投影；层级靠底色和 1px 线。唯一的投影 `--mw-shadow-overlay` 只给弹层/抽屉。
- 色轨 `--mw-rail: 4px`：区块小标题前的短色条、行左侧竖轨、面板顶边、选中态底边。

### 5.2 基础元件（`design-tokens.css`）

| 类 | 说明 |
| --- | --- |
| `.mw-button` + `--primary / --secondary / --small` | 主按钮墨色实底；次按钮白底墨色描边；高度 48 / 40px（触控 ≥ 44） |
| `.mw-text-link` | 文字链接，2px 下划线取线路色 |
| `.mw-kicker` | 区块小标题：短色条 + 中文 |
| `.mw-line-badge` | 线路标（`C++`、`Python`、`科创`），白字压 text 档；科创为芥黄底墨字 |
| `.mw-station` + `[data-state]` | 站点：空心 = 未学，带芯 = 学习中，实心 = 已过关，芥黄 = 建议复习；`--interchange` 为换乘胶囊 |
| `.mw-code`、`.mw-code-line[data-line][data-active]` | 深色代码块，行号不可复制，当前行芥黄高亮 |
| `.mw-sr-only` | 仅供读屏 |

### 5.3 交互状态

- 悬停：描边加深或底色换一档、标题出现线路色下划线；**不做上浮、缩放、旋转**。
- 焦点：`2px` 墨色描边、`3px` 偏移；深色区改芥黄。整卡可点的卡片用「拉伸链接」（标题里的 `<a>` 用 `::after` 盖住卡片），焦点框画在 `::after` 上。
- 选中：切换按钮用 `aria-pressed`，视觉为线路色浅底 + 4px 底边。
- 动效：时长 160ms，只表达状态变化；`prefers-reduced-motion` 下全部关闭。自动演示必须可暂停，且一碰按钮就停。

## 6. 导航与页脚

- `Navigation variant="home"`：高 64px 固定；顶部与页面同为 canvas，滚动后变白底加细线；无毛玻璃、无投影。导航项为文字按钮，悬停/当前项出现朱橙 2px 底线；「开始练习」用小号主按钮。手机菜单是整页站牌列表（行高 60px、细线分隔）。
- `Footer variant="home"`：深色；顶部 6px 四色线路色带（全站唯一的多色装饰）；三栏：站点说明 / 课程线路 / 练习与资源；链接用真 `<a>`。
- 不传 `variant` 时导航和页脚保持旧样式，其他页面暂不受影响。

## 7. 各类页面的应用建议

### 7.1 课程目录（已在首页落地）

- 体系切换 = 选线路：4 个等宽按钮，1px 间隙当分隔线，选中为线路浅底 + 底边。
- 课段切换 = 选区间：线路标（`L1`、`F1-F7`、`A1-A9`、`15 课`）+ 课段名 + 上线状态。
- 课时 = 站点：编号圈即站点（未学空心、学习中带芯、已过关实心带 ✓、建议复习芥黄、建设中虚线），旁边永远写状态文字。真实链接用 `<a>`，未建成的课不做成可点的按钮。

### 7.2 题库

- 题库是换乘站：深色「换乘大厅」或墨色线路标。
- 统计数字用导视数字字体、等宽数字；核验状态用比例条 + 图例 + 文字，三档：完整核验（ok）、部分核验（芥黄）、待核验（灰斜纹）。风险题用 warn + 图标 + 原因说明。
- 题目卡：白底细线面板；选项是 6px 圆角的整行按钮，选中为墨色描边，不用彩色实底。

### 7.3 课件（课程页）

- 课程页顶栏换成本课所属线路：线路标 + 「GESP C++ 三级 · 第 7 课」+ 课时编号圈。
- 正文宽 ≤ 42em、15–17px、行高 1.8；小节标题用 `.mw-kicker` 形式。
- `PredictCheck` / `MasteryCheck` / `TransferCheck` 这类教学组件统一成白底细线面板，顶边 4px 线路色。

### 7.4 代码

- 代码块统一用 `.mw-code`：深色、等宽、行号不可复制、当前行芥黄高亮 + 左侧 3px 芥黄条。
- 语法高亮从 token 取：关键字朱橙浅色、字符串松绿浅色、数字芥黄、注释 `--mw-on-night-muted`。
- 逐行推演配「变量表」：表头 2px 墨线，行固定高度，未执行的行留空，当前行芥黄浅底；说明列在窄屏收起，改由下方状态文字显示。

### 7.5 练习反馈

| 场景 | 样式 |
| --- | --- |
| 答对 | `--mw-ok-tint` 底 + `--mw-ok` 左边 4px + ✓ 图标 + 「答对了」 |
| 答错 | `--mw-err-tint` 底 + `--mw-err` 左边 4px + ✕ 图标 + 「再想想」+ 原因 |
| 提示 / 待核验 | `--mw-warn-tint` 底 + 图标 + 说明来源 |
| 进度 | 用站点圆点，不用百分比环形图 |

不用整块大红/大绿底、不用表情包式庆祝动画；成功反馈一句话说清学到了什么。

## 8. 无障碍底线

- 文字对比 ≥ 4.5:1（大字 ≥ 3:1），图形元素 ≥ 3:1；上面每个文字 token 都已核算。
- 触控目标 ≥ 44×44px（线路图站点在桌面为整列宽、56px 高）。
- 语义：跳转用 `<a>`（`Link`），操作用 `<button>`；切换按钮带 `aria-pressed`；图表有 `role="img"` 摘要和可见的图例文字。
- 可横向滚动的区域要能被键盘聚焦（`tabIndex=0` + `role="region"` + `aria-label`）。
- 自动播放的演示要有暂停按钮，并尊重 `prefers-reduced-motion`。
