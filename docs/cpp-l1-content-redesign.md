## 1. 设计原则

1. **考纲导向，真题验收**。每个知识点都要能对应到考纲条目或站内一级真题。仓库里没有考纲原文的条目标“待核实”。仓库文档已确认属于二级及以上的内容（ASCII 系统、多层循环、数学函数、数组、进制）不进一级核心。
2. **一课一个新能力**。每课只新增一种语法或一种解题套路，能用一句“学完能……”验收。课名用考纲能力名。
3. **固定五步**：概念 → 例题（完整代码和逐字输出）→ 易错点 → 课堂练习（先预测再验证）→ 真题（作答后才显示解析），最后两道上机题收尾（基础 1、提高 1）。
4. **去重**。同一内容只在一课主讲，其他课只复用、不重讲：数位分离只在第 13 课讲，逻辑运算只在第 7 课讲。必须重访时写明新增了什么能力。
5. **递进到 L2**。一级只处理“单层循环 + 单个数”。嵌套循环、ASCII 编码、数学函数、质数试除优化留给二级，第 12、15、16 课写明二级入口。

**四段主线**（对应主线 v2 的“写对程序”）：

- A 顺序程序（1–6）：输入—计算—输出，表达式与格式要逐字正确。
- B 分支（7–9）：会写条件，会选分支。
- C 循环（10–13）：单层循环的次数、终点、跳转，以及最典型的循环应用（数位）。
- D 综合（14–16）：一级编程题的两种主型——“读 n 个数统计”和“按定义检验”，最后整卷测评。

**阶段诊断**（升级规划 §4 规定的第 4、8、12、16 课节点）：

- 诊断 A 放在第 4 课末，覆盖 1–4 课。

### 第 3 课：整除、取余与优先级（原第 4 课内容 + 原第 3 课的优先级真题）

- **对应考点**：E1、H1。
- **前置知识**：会定义 `int` 变量、用 `cin` 读入、用 `cout` 输出表达式的值（第 2 课）。
- **本课新增能力**：能用 `/` 和 `%` 求商和余数，按优先级手算混合表达式，完成时间换算和三位数拆分。
- **讲解顺序**：
  1. 概念：
     - 两个整数相除，`/` 得到商，小数部分直接舍去；`%` 得到余数。
     - 被除数 = 除数 × 商 + 余数。`%` 两边都必须是整数，除数不能为 0。
     - 优先级分三层：括号最先；`*` `/` `%` 同级，从左到右；`+` `-` 最后。
     - 本课只用非负整数。负数的商与余数放在第 4 课说明（向 0 截断）。
  2. 例题：
     - 例 1，输出 `2 5`、`3 2`、`0 2`：

       ```cpp
       int n = 125;
       cout << n / 60 << " " << n % 60 << endl;
       cout << 17 / 5 << " " << 17 % 5 << endl;
       cout << 2 / 5 << " " << 2 % 5 << endl;
       ```

     - 例 2，输出 `1`、`-18`、`4`，逐步写出每一步：

       ```cpp
       cout << 10 - 3 * (2 + 1) % 10 << endl;
       cout << 9 / 4 - 6 % (6 - 2) * 10 << endl;
       cout << 2 + 3 * 4 % 5 << endl;
       ```

     - 例 3，输入 `472`，输出 `4 7 2`：

       ```cpp
       int n;
       cin >> n;
       int a = n / 100;      // 百位
       int b = n / 10 % 10;  // 十位
       int c = n % 10;       // 个位
       cout << a << " " << b << " " << c << endl;
       ```

  3. 易错点：
     - `2 / 5` 是 0 不是 0.4，`2 % 5` 是 2。
     - `*` `/` `%` 同级，要从左到右算，不能先算 `%`。
     - `^` 不是乘方。
     - `/` 和 `%` 不能互换，即使某个例子里两者结果碰巧相同（2024-09 判断第 2 题）。
     - 除数为 0。
  4. 课堂练习（先预测再验证）：
     - `16 / 4 % 2`（得 0）。
     - `10 - 3 * (2 + 1) % 10`（得 1，题源 2023-12 单选 2 ◇）。
     - 现在 10 点，N 小时后是几点：`(10 + N) % 24`（题源 2023-12 单选 3 ◇）。
     - 三位数十位的写法：`(i / 10) % 10`（题源 2025-06 单选 15 ◇）。

### 第 4 课：数据类型与类型转换（原第 3 课 + 原第 5 课的 `char`/`bool` 核心）

- **对应考点**：D1–D3、H5。
- **前置知识**：整数除法与取余（第 3 课）。
- **本课新增能力**：能判断表达式的结果类型，说明小数存入 `int` 会向 0 截断，并按要求输出固定位数的小数。
- **讲解顺序**：
  1. 概念：
     - 一级常用类型：

       | 类型 | 字面量示例 | 常见字节数 |
       | --- | --- | --- |
       | `int` | `10` | 通常 4 |
       | `double` | `3.0` | 通常 8 |
       | `float` | — | 通常 4 |
       | `char` | `'3'` | 1（标准规定） |
       | `bool` | `true` / `false` | — |
       | 字符串字面量（不是变量类型） | `"3"` | — |

       `long long` 是否属一级待核实，只作“范围更大的整数”提一句。
     - 两个 `int` 运算结果是 `int`；只要有一个是 `double`，结果就是 `double`。
     - 小数存入 `int` 向 0 截断：`2.9 → 2`，`-2.9 → -2`；负数的整数除法同理，`-7 / 2` 得 -3。
     - 强制转换写法：`int(x)`、`(int)x`、`(double)a / b`。
     - 字符串不能和数直接运算：`"10" * 2` 编译报错。
     - `char` 用 `cin` 读入时只读走一个字符；`bool` 用 `cout` 输出显示 1 或 0。
  2. 例题：
     - 例 1，输出 `3`、`3.5`、`3.5`、`3`、`2 -2`：

       ```cpp
       int a = 7, b = 2;
       cout << a / b << endl;
       cout << a / 2.0 << endl;
       cout << (double)a / b << endl;
       cout << 0.0 + a / b << endl;
       int c = 2.9, d = -2.9;
       cout << c << " " << d << endl;
       ```

       注意：编译器对 `int c = 2.9` 只给警告，仍能编译。第 4 行的 `0.0 + a / b` 中 `a / b` 先算出 3，所以结果是 3。
     - 例 2，输出 `80.5`、`80.50`：

       ```cpp
       double avg = (80 + 81) / 2.0;
       cout << avg << endl;
       cout << fixed << setprecision(2) << avg << endl;
       ```

     - 例 3，输入 `10`，输出 `1 1`（`c` 只读到字符 `'1'`）：

       ```cpp
       char c;
       bool ok = (3 > 2);
       cin >> c;
       cout << c << " " << ok << endl;
       ```

  3. 易错点：
     - `(double)(a / b)` 已经晚了，要写成 `(double)a / b`。
     - `3.0` 和 `3` 值相等，但类型和占用空间不同。
     - `cout` 默认不会把 2.5 显示成 `2.50`。
     - `fixed << setprecision(n)` 一旦设置，对后面所有输出都有效。
     - `'A'` 与 `"A"` 不同；`'AB'` 不是一个字符。

### 第 5 课：赋值与自增自减（新课）

- **对应考点**：E2。
- **前置知识**：变量再次赋值（第 2 课），整数运算（第 3 课）。
- **本课新增能力**：能手推赋值、复合赋值、`i++`/`++i` 和逗号表达式后的变量值，完成两数交换。
- **讲解顺序**：
  1. 概念：
     - `=` 是赋值不是相等：先算右边，再存进左边。左边必须是变量，`a + c = b + c` 不合法。
     - 赋值表达式本身有值，值就是赋完后的左边，所以 `b = a = 4` 从右往左执行。
     - `a op= x` 等价于 `a = a op (x)`，所以 `a *= 2 + 3` 是乘 5。
     - `i++` 和 `++i` 单独成句时效果相同；放在表达式里时，`x++` 先用旧值再加 1，`++x` 先加 1 再用新值。
     - 逗号运算符从左到右依次计算，整个表达式的值是最后一项。
  2. 例题：
     - 例 1，复合赋值，输出 `15`、`12`、`24`、`4`、`1`：

       ```cpp
       int a = 10;
       a += 5;  cout << a << endl;
       a -= 3;  cout << a << endl;
       a *= 2;  cout << a << endl;
       a /= 5;  cout << a << endl;
       a %= 3;  cout << a << endl;
       ```

     - 例 2，自增，输出 `5`、`6`、`7`、`2 1`：

       ```cpp
       int x = 5;
       cout << x++ << endl;
       cout << x << endl;
       cout << ++x << endl;
       int i = 0, s = 0;
       s += i++;
       s += i++;
       cout << i << " " << s << endl;
       ```

     - 例 3，连续赋值与逗号表达式，输出 `4 4`、`5`：

       ```cpp
       int a, b;
       a = 3;
       b = a = 4;
       cout << a << " " << b << endl;
       int X;
       cout << (X = 3, X++, ++X) << endl;
       ```

     - 例 4，借第三个变量交换，输出 `8 3`：

       ```cpp
       int a = 3, b = 8, t;
       t = a; a = b; b = t;
       cout << a << " " << b << endl;
       ```

  3. 易错点：
     - 先写 `a = b;` 再写 `b = a;` 交换不了。
     - `N % 2 = 0` 编译失败。
     - 同一个表达式里对同一变量既读又改（如 `x = x++`、`cout << i << i++`）结果不可依赖，不要写。逗号运算符除外。
     - 把整数变量当作能存 20.24（2024-09 判断第 5 题：X 先被截成 20）。
  4. 课堂练习：
     - `a = 6; a %= 4;` 后 a 的值（得 2，题源 2023-06 单选 10 ◇）。
     - 横线填空使输出 `20 10`（题源 2023-06 单选 13 ◇）。
     - `x = x + y; y = x - y; x = x - y;` 的结果（题源 2025-06 单选 6 ◇）。
     - 选学：`++a += 3`、`(++x)++` 的结果（题源 2025-06 单选 7、8 ◇；本机 C++11 实测分别为 20 和“输出 9，x 为 10”，是否原题待核实）。
  5. 真题：2025-12 单选 6（`b = a = 4`）、单选 4（`(X=3, X++, ++X)` 得 5）。
- **上机**：
  - **5-A 基础：交换两个数**（新增）
    - 输入一行两个整数 a、b（-10⁶ ≤ a, b ≤ 10⁶）。先交换两个变量的值，再按 `a b` 的顺序输出。
    - 样例：`3 8` → `8 3`；`5 5` → `5 5`。
    - 核心：`t = a; a = b; b = t;`
  - **5-B 提高：复合赋值连算**（新增）
    - 输入整数 x（0 ≤ x ≤ 1000）。依次执行 `x += 5`、`x *= 3`、`x -= 4`、`x /= 2`、`x %= 7`，每执行一步输出一次 x，五个数在同一行，空格分隔。必须用复合赋值写。
    - 样例：`3` → `8 24 20 10 3`；`0` → `5 15 11 5 5`。

### 第 6 课：格式化输入输出（新课）

- **对应考点**：B3、F1、F2、H5。
- **前置知识**：`cout`/`cin`（第 1、2 课），`double` 和保留小数（第 4 课）。
- **本课新增能力**：能用 `printf` 控制宽度、补零、小数位和 `%` 的输出，并预测 `scanf`/`cin` 遇到非数字字符时读到什么。
- **讲解顺序**：
  1. 概念：
     - `printf(格式串, 参数…)` 需要 `<cstdio>`。格式串里的普通字符原样输出，占位符按顺序换成参数的值。
     - 占位符：`%d` 整数、`%f` 小数、`%.2f` 两位小数、`%c` 字符、`%%` 输出一个 `%`。
     - 宽度：`%3d` 右对齐、不足补空格；`%03d` 补 0；`%-5d` 左对齐。
     - 参数的个数和类型要与占位符一致：`printf("%d", 3.14)` 通常能编译，但输出不可靠。
     - `scanf("%d%d", &a, &b)` 必须写 `&`；读 `double` 用 `%lf`。
     - `scanf` 和 `cin` 读整数时都以空白分隔，遇到不能组成整数的字符就停：输入 `14+7` 只读到 14。
     - 考试程序不要输出“请输入”这类提示语。
  2. 例题：
     - 例 1，输出 `9:5`、`09:05`、`[  7][7  ]`、`5%2=1`、`3.14`：

       ```cpp
       int h = 9, m = 5;
       printf("%d:%d\n", h, m);
       printf("%02d:%02d\n", h, m);
       printf("[%3d][%-3d]\n", 7, 7);
       printf("5%%2=%d\n", 5 % 2);
       double p = 3.14159;
       printf("%.2f\n", p);
       ```

     - 例 2，输入 `10 20`，输出 `30`：

       ```cpp
       int a, b;
       scanf("%d%d", &a, &b);
       printf("%d\n", a + b);
       ```

     - 例 3，输入 `14+7`，输出 `14`；把 `scanf` 换成 `cin >> P;` 结果相同：

       ```cpp
       int P;
       scanf("%d", &P);
       printf("%d\n", P);
       ```

  3. 易错点：
     - 漏 `&`。
     - 把 `%%` 写成 `%`。
     - `printf("%d*2", N)` 输出的是 `5*2` 而不是 10。
     - `%-5d` 的减号是左对齐，不会被输出。
     - 以为 `scanf` 能输出提示语。
     - `cout` 与 `printf` 保留小数的对照：`fixed << setprecision(2)` 对应 `%.2f`。
  4. 课堂练习：
     - `printf("__ %02d%2d", 3, 22)` 输出什么（得 `__ 0322`，题源 2025-03 单选 6 ◇）。
     - `printf("{N}*{N}={%d*%d}", N, N, N * N)`（题源 2025-03 单选 10 ◇）。
     - `printf("a+b=%02d#a+b={a+b}", a + b, a + b)`（题源 2025-06 单选 9 ◇）。
  5. 真题：
     - 2024-06 单选 4（`%%`）、单选 6（`%.0f`）、单选 5（`cin` 读 `5+2`）、判断 4。
     - 2024-03 单选 3、5、12，判断 2、判断 3。
     - 2024-09 单选 11（`scanf` 读 `14+7`）、判断 3。
     - 2025-12 判断 8。
- **上机**：
  - **6-A 基础：时间格式**（新增）
    - 输入一行两个整数 h、m（0 ≤ h ≤ 23，0 ≤ m ≤ 59），按 `HH:MM` 格式输出，不足两位补 0。要求用 `scanf` 和 `printf`。
    - 样例：`9 5` → `09:05`；`23 59` → `23:59`。
    - 核心：`printf("%02d:%02d\n", h, m);`
  - **6-B 提高：正确率**（新增）

    - 样例：`3 4` → `75.0%`；`1 3` → `33.3%`。
    - 核心：`printf("%.1f%%\n", a * 100.0 / b);`

### 第 7 课：关系与逻辑运算（原第 6 课 + 原第 7 课“比较符号” + 原第 13 课的条件翻译和闰年）

- **对应考点**：E3。
- **前置知识**：`bool` 显示 1/0（第 4 课），`%` 判断整除（第 3 课）。
- **本课新增能力**：能把“且、或、非、区间、倍数”翻译成 C++ 条件表达式，并手推短路和优先级。
- **讲解顺序**：
  1. 概念：
     - 六个关系运算符，结果是 `bool`，`cout` 显示 1 或 0。`=` 是赋值，`==` 是比较。
     - `&&` 两边都真才真，`||` 一边真就真，`!` 取反。整数转成真假时，0 为假，非 0 为真。
     - 短路：`&&` 左边为假、`||` 左边为真时，右边不执行。
     - 优先级从高到低：`!` → 算术 → `<` `<=` `>` `>=` → `==` `!=` → `&&` → `||`。不确定时加括号。
     - 常用条件翻译：
       - 偶数 `n % 2 == 0`，奇数 `n % 2 != 0`（对负数也对）。
       - k 的倍数 `n % k == 0`，个位是 k：`n % 10 == k`。
       - 区间 `x >= 8 && x <= 12`。
       - 闰年 `(y % 4 == 0 && y % 100 != 0) || y % 400 == 0`。
  2. 例题：
     - 例 1，输出 `1 0`、`0 1`、`0 1`：

       ```cpp
       int x = 7;
       cout << (x > 3) << " " << (x == 5) << endl;
       cout << (x > 3 && x < 5) << " " << ((3 < x) < 5) << endl;
       cout << (!x) << " " << (!!x) << endl;
       ```

       第二行右边说明 `3 < x < 5` 实际按 `(3 < x) < 5` 计算，结果总为 1。
     - 例 2，短路，输出 `0`、`1 2 0`（n 没有被改成 5）：

       ```cpp
       int a = 0, b = 0;
       if (a != 0 && 10 / a > 2) b = 1;
       cout << b << endl;
       int m = 0, n = 0;
       bool r = (m = 2) || (n = 5);
       cout << r << " " << m << " " << n << endl;
       ```

     - 例 3，输出 `0`、`0`（72 是 8 的倍数）：

       ```cpp
       int y = 1900, a = 72;
       cout << ((y % 4 == 0 && y % 100 != 0) || y % 400 == 0) << endl;
       cout << (a % 9 == 0 && a % 8 != 0) << endl;
       ```

  3. 易错点：
     - 链式比较 `3 < x < 5`：按 C++11 标准是合法表达式，但不表示区间。本机 Apple clang 21 直接把它判为编译错误，GCC 一般只给警告（本机未验证 GCC）。课页统一用加括号的写法演示它的实际含义。
     - `!!N` 的值是 0 或 1，不是 N。
     - `||` 与 `&&` 混写时 `&&` 先算（2025-12 判断第 7 题：输入 8 时条件为真）。
     - 用 `n % 2 == 1` 判断负奇数会出错。
  4. 课堂练习：
     - `(5 && 2)`、`(a = 2) && (b = 0)` 后 a、b 的值（题源 2023-03 单选 9、10 ◇）。
     - 三角形三边条件（题源 2023-03 单选 12 ◇）。
     - `x < y || !(x < z)`（题源 2023-09 单选 5 ◇）。
     - “能被 2 整除且除以 7 余 2”的四种写法辨析（题源 2025-03 单选 12 ◇）。
  5. 真题：2024-09 判断 10（`a < b < c`）、2024-06 判断 9（`!!N`）。
- **上机**：
  - **7-A 基础：活动资格**（沿用 `cpp-1-6`，课次由 6 改为 7）
    - 年龄在 8～12 岁（含两端）且已报名时输出 1，否则输出 0。输入一行两个整数 age、registered（1 ≤ age ≤ 100，registered 为 0 或 1）。
    - 样例：`8 1` → `1`；`12 0` → `0`。
  - **7-B 提高：三角形判断**（新增）
    - 输入一行三个正整数 a、b、c（1 ≤ a, b, c ≤ 1000）。能构成三角形（任意两边之和大于第三边）时输出 1，否则输出 0。要求直接输出一个条件表达式的值。

### 第 8 课：if 与 if-else（原第 7 课 + 原第 14 课的买文具与小杨的考试）

- **对应考点**：G1、E4（选学）。
- **前置知识**：条件表达式（第 7 课）。
- **本课新增能力**：能写二分支程序，求两数较大值、较小值和差的绝对值，识别分号、大括号和条件中误用赋值的陷阱。
- **讲解顺序**：
  1. 概念：
     - `if (条件) 语句;` 条件为真时执行；`if … else …` 二选一；`else` 可以省略。
     - 不加大括号时，`if` 只管紧跟的一条语句。
     - `if (条件);` 的分号让后面的代码失去条件控制。
     - `if (x = 0)` 永远为假且把 x 改成 0；`if (x = 5)` 永远为真。
     - 取余结果为 0 时按题意修正，比如星期日用 7 表示。
     - 选学：`条件 ? 值1 : 值2`。
  2. 例题：
     - 例 1，输入 `10 20`，输出 `20 10`：

       ```cpp
       int a, b;
       cin >> a >> b;
       int mx = a;
       if (b > mx) mx = b;
       int diff;
       if (a > b) diff = a - b;
       else diff = b - a;
       cout << mx << " " << diff << endl;
       ```

     - 例 2，缩进不影响执行，输出 `10 10`：

       ```cpp
       int a = 10, b = 20;
       if (a > b) a = b;
       b = a;
       cout << a << " " << b << endl;
       ```

     - 例 3，输入 `6 8`（星期六过 8 天），输出 `7`：

       ```cpp
       int x, n;
       cin >> x >> n;
       int d = (x + n) % 7;
       if (d == 0) d = 7;
       cout << d << endl;
       ```

     - 例 4（选学），输出 `8`：

       ```cpp
       int a = 3, b = 8;
       cout << (a > b ? a : b) << endl;
       ```

  3. 易错点：

### 第 9 课：多分支与 switch（原第 8 课 + 原第 13 课《每月天数》）

- **对应考点**：G2、G3。
- **前置知识**：`if-else`（第 8 课），闰年条件（第 7 课）。
- **本课新增能力**：能预测 `else if` 命中哪一支，按区间分档，用 `switch` 处理固定选项并解释穿透。
- **讲解顺序**：
  1. 概念：
     - `if / else if / else` 从上往下检查，命中第一个成立的分支后就不再检查后面的条件；`else` 兜底。
     - 区间分档从高到低写，后面的条件可以省掉上界。
     - 要求“几个条件都要检测”时用多个独立的 `if`。
     - `switch (整数或字符表达式)`：`case` 后跟常量；从匹配的 `case` 开始往下执行，遇到 `break` 跳出；`default` 处理其余值。
     - 不写 `break` 会穿透到下一个 `case`。几个 `case` 可以合用一段代码。
     - `break` 只能用在循环或 `switch` 里。
  2. 例题：
     - 例 1，输出 `B`：

       ```cpp
       int s = 85;
       if (s >= 90) cout << "A";
       else if (s >= 80) cout << "B";
       else if (s >= 60) cout << "C";
       else cout << "D";
       cout << endl;
       ```

     - 例 2，穿透，输出 `two`、`three`：

       ```cpp
       int k = 2;
       switch (k) {
           case 1: cout << "one" << endl;
           case 2: cout << "two" << endl;
           case 3: cout << "three" << endl; break;
           default: cout << "other" << endl;
       }
       ```

     - 例 3，每月天数，输入 `2024 2` 输出 `29`，输入 `2100 2` 输出 `28`：

       ```cpp
       int y, m, d;
       cin >> y >> m;
       switch (m) {
           case 1: case 3: case 5: case 7: case 8: case 10: case 12:
               d = 31; break;
           case 4: case 6: case 9: case 11:
               d = 30; break;
           default:
               if ((y % 4 == 0 && y % 100 != 0) || y % 400 == 0) d = 29;
               else d = 28;
       }
       cout << d << endl;
       ```

  3. 易错点：
     - 条件顺序写反，比如先判 `s >= 60` 会把 90 分也分到 C。
     - 该用两个独立 `if` 的地方用了 `else if`（输入 21 时只输出“能被3整除”）。
     - `case` 后面写变量或区间（`case score >= 90:` 不是区间判断）。
     - 漏写 `break`。
     - 把 `break` 写进不在循环里的 `if`，编译失败。
  4. 课堂练习：
     - 2023-09 单选 7、8、9 ◇（`else if` 链）。

### 第 10 课：for 循环（原第 9 课；补调试）

- **对应考点**：G4、A4（调试）。
- **前置知识**：`i++`、`+=`（第 5 课），条件（第 7 课）。
- **本课新增能力**：能手推 `for` 的执行次数和结束时的变量值，完成计数、累加、累乘，并用单步调试核对。
- **讲解顺序**：
  1. 概念：
     - 执行顺序：初始化（只执行一次）→ 判断 → 循环体 → 更新 → 判断……
     - `for (i = a; i < b; i++)` 执行 b−a 次，`i <= b` 时执行 b−a+1 次。步长不是 1 时，先列出 i 的取值再数。
     - 循环结束时，i 是第一个让条件变假的值。
     - 要在循环外读 i，就把 i 声明在循环外。
     - 计数器、累加器先清 0；累乘器初值为 1。
     - 三段都可以省略。`for (…);` 的分号使循环体变成空语句。
     - 在循环体里改 i 会改变次数。
     - 调试：断点是让程序停在某一行，单步执行时查看变量，就是一张机器生成的追踪表。
  2. 例题：
     - 例 1，输出 `3 10`：

       ```cpp
       int i, cnt = 0;
       for (i = 1; i < 10; i += 3) {
           cnt++;
       }
       cout << cnt << " " << i << endl;
       ```

     - 例 2，累计相加，输入 `4` 输出 `10 20`，输入 `10` 输出 `55 220`：

       ```cpp
       int n, s = 0, total = 0;
       cin >> n;
       for (int i = 1; i <= n; i++) {
           s += i;
           total += s;
       }
       cout << s << " " << total << endl;
       ```

     - 例 3，自增在循环里，输出 `10 45`：

       ```cpp
       int Sum = 0, i = 0;
       for ( ; i < 10; ) Sum += i++;
       cout << i << " " << Sum << endl;
       ```

     - 例 4，空循环体，输出 `4`：

       ```cpp
       int total = 0, i;
       for (i = 1; i < 4; i++);
       total += i;
       cout << total << endl;
       ```

  3. 易错点：
     - 把“最后一次进入循环体时的 i”当作“结束后的 i”。
     - 累加器未初始化（值无法确定）。
     - `i < 100` 共执行 100 次，不是 99 次。
     - 累乘从 i = 0 开始，结果恒为 0。
     - 以为 `for` 不可能是死循环。
  4. 课堂练习：
     - `for (int i = -10; i < 10; i++)` 执行几次。
     - `cnt += 1; i += 2;` 写在循环体里时的次数（题源 2023-12 单选 6 ◇，得 3）。
     - -1000 到 999 求和（题源 2025-03 单选 13 ◇，得 -1000）。
     - `n += i % 2` 对 0～99 求和（题源 2025-09 单选 8 ◇，得 50）。
     - 断点题（题源 2025-06 单选 2 ◇、2025-09 单选 15 ◇）。

### 第 11 课：while 与 do-while（原第 10 课，去掉数位分离）

- **对应考点**：G5。
- **前置知识**：`for` 的执行顺序（第 10 课）。
- **本课新增能力**：能用 `while` 处理次数事先不知道的过程，并说明 `do-while` 至少执行一次。
- **讲解顺序**：
  1. 概念：
     - `while (条件) { … }` 先判断后执行，可能一次都不执行。
     - 循环体内必须有让条件最终变假的语句，否则死循环。
     - `for` 和 `while` 可以互相改写。
     - `do { … } while (条件);` 先执行后判断，至少执行一次，结尾有分号。
     - `while (1)` 必须配一条能执行到的 `break`。
     - “读到 0 为止”：先读一个数，循环里处理完再读下一个。
  2. 例题：
     - 例 1，输出 `4`（13→6→3→1→0）：

       ```cpp
       int n = 13, steps = 0;
       while (n > 0) {
           n /= 2;
           steps++;
       }
       cout << steps << endl;
       ```

     - 例 2，输出 `0 1`：

       ```cpp
       int a = 10, c1 = 0, c2 = 0;
       while (a < 5) { c1++; a++; }
       int b = 10;
       do { c2++; b++; } while (b < 5);
       cout << c1 << " " << c2 << endl;
       ```

     - 例 3，输入 `5 3 -2 0` 输出 `6 3`，输入 `0` 输出 `0 0`：

       ```cpp
       int x, sum = 0, cnt = 0;
       cin >> x;
       while (x != 0) {
           sum += x;
           cnt++;
           cin >> x;
       }
       cout << sum << " " << cnt << endl;
       ```

  3. 易错点：
     - 更新语句放错位置，比如 2024-06 单选 11 的 C 选项把 `i += 1` 前移后，累加的是偶数。
     - `while (N) cout << N;` 要么一次不执行，要么停不下来。
     - `do-while` 结尾漏分号。
  4. 课堂练习：
     - `while (n < 5)` 一次不执行（题源 2023-09 单选 11 ◇）。
     - n 每次减 2、计数器从 1 开始（题源 2023-09 单选 12 ◇，得 4）。
     - `while (1)` + `break`（题源 2023-12 单选 8 ◇，得 5）。
     - 两个变量相向变化（题源 2025-06 单选 11 ◇，得 `5 6`）。
  5. 真题：2024-03 单选 9（`9#6#3#0#`）、2025-12 单选 12（更相减损法）。
- **上机**：
  - **11-A 基础：每次减半**（新增）
    - 输入正整数 n（1 ≤ n ≤ 10⁹）。反复执行 n = n / 2（整数除法），直到 n 为 0，输出执行了几次。
    - 样例：`13` → `4`；`1` → `1`。另测 `1000000000` → `30`。
  - **11-B 提高：更相减损**（新增）
    - 输入一行两个正整数 a、b（1 ≤ a, b ≤ 1000）。只要两数不相等，就用大数减去小数替换大数，直到两数相等，输出这个数。
    - 样例：`12 18` → `6`；`7 7` → `7`。

### 第 12 课：break 与 continue（原第 11 课；嵌套部分删去）

- **对应考点**：G6。
- **前置知识**：`for`、`while`（第 10、11 课），`switch` 里的 `break`（第 9 课）。
- **本课新增能力**：能追踪 `break`、`continue` 后程序去哪一步，用“找到就停”的写法求第一个满足条件的数。
- **讲解顺序**：
  1. 概念：
     - `break` 立即结束它所在的那一层循环（或 `switch`），接着执行循环后面的语句。
     - `continue` 跳过本轮剩下的语句：在 `for` 里跳到更新，在 `while` 里跳回条件判断。
     - 两者通常和 `if` 一起用。
     - `break` 后循环变量停在触发时的值。
     - `while` 里如果 `continue` 写在更新语句前面，会死循环。
     - 一级只讲单层循环。“只退出最近一层”在二级的嵌套循环里再验证。
  2. 例题：
     - 例 1，输出 `1245`、`12`：

       ```cpp
       for (int i = 1; i <= 5; i++) {
           if (i == 3) continue;
           cout << i;
       }
       cout << endl;
       for (int i = 1; i <= 5; i++) {
           if (i == 3) break;
           cout << i;
       }
       cout << endl;
       ```

     - 例 2，找到第一个就停，输出 `12`：

       ```cpp
       int m = 4, n = 6, ans = 0;
       for (int d = 1; d <= m * n; d++) {
           if (d % m == 0 && d % n == 0) {
               ans = d;
               break;
           }
       }
       cout << ans << endl;
       ```

     - 例 3，`while` 中的 `continue`，输出 `12`（1+2+4+5）：

       ```cpp
       int i = 0, s = 0;
       while (i < 5) {
           i++;
           if (i == 3) continue;
           s += i;
       }
       cout << s << endl;
       ```

  3. 易错点：
     - 以为 `continue` 会结束循环。
     - 以为 `break` 不能用在 `for` 里。
     - 只有 `continue` 的循环结束后 i 是终值，不是 0（2025-12 判断 3）。

### 第 13 课：数位分离（原第 4 课的三页数位 + 原第 10 课的数位分离与位数修复）

- **对应考点**：H2。
- **前置知识**：`/` 与 `%`、固定三位数拆分（第 3 课），`while`（第 11 课），`break`（第 12 课）。
- **本课新增能力**：能用 `%10` 和 `/10` 逐位处理位数未知的整数，完成位数、数位和、反转与替换。
- **讲解顺序**：
  1. 概念：
     - 对非负整数 n，`n % 10` 取个位，`n /= 10` 去掉个位。
     - 模板：`while (n > 0) { d = n % 10; …处理 d…; n /= 10; }`。
     - 循环会把 n 变成 0，所以要输出原数时先备份（`n0 = n`）。
     - n = 0 时循环一次也不执行：求位数要特判，求数位和自然得 0。
     - 反转：`r = r * 10 + n % 10`。
     - 按位重建：`b += d * p; p *= 10;`。
     - 固定位数仍用第 3 课的写法：千位 `n / 1000`，十位 `n / 10 % 10`。

     - 例 1，输入 `3050`，输出 `3050 4 8`：

       ```cpp

       while (n > 0) {
           sum += n % 10;
           cnt++;
           n /= 10;
       }
       cout << n0 << " " << cnt << " " << sum << endl;
       ```

     - 例 2，输出 `21`：

       ```cpp

       ```

       ```cpp
       cin >> a;

           int d = a % 10;
           if (d == 3) d = 7;
           b += d * p;
           p *= 10;
           a /= 10;

       cout << b << endl;
       ```

       2026-03 编程 2《数字替换》（把 4 换成 8）与本例同型。该卷留作第 16 课测评，所以这里换了数字，测评讲评时再回到本例。

### 第 14 课：循环读入与统计（原第 15 课的计数与筛选 + 原第 13 课《美丽数字》）

- **讲解顺序**：

### 第 15 课：因数、质数与平方数（原第 15 课的因数扫描仪 + 新内容）

- **对应考点**：H4。
- **前置知识**：`for` 计数（第 10 课），`break`（第 12 课），`bool` 标志（第 4 课）。
- **本课新增能力**：能按定义逐个检验 1～n，判断因数、质数、完全平方数和立方数。
- **讲解顺序**：
  1. 概念：
     - 因数：`for (i = 1; i <= n; i++) if (n % i == 0)`，i 必须从 1 开始，除数不能为 0。
     - 质数（计数法）：恰有 2 个因数，1 不是质数。
     - 质数（标志法）：先设 `flag = true`，在 2～n−1 中找到因数就置 false 并 `break`；n < 2 时直接不是质数。
     - 完全平方数：存在 i 使 `i * i == n`，循环条件写 `i * i <= n` 可以提前停。
     - 立方数同理，写 `x * x * x <= n`。
     - 一级只要求按定义逐个试。“试到 √n 就够”和溢出分析放在二级 L2-9。
  2. 例题：
     - 例 1，输出 `6`：

       ```cpp
       int n = 12, cnt = 0;
       for (int i = 1; i <= n; i++) {
           if (n % i == 0) cnt++;
       }
       cout << cnt << endl;
       ```

     - 例 2，输出 `Yes`：

       ```cpp
       int n = 7, cnt = 0;
       for (int i = 1; i <= n; i++)
           if (n % i == 0) cnt++;
       if (cnt == 2) cout << "Yes" << endl;
       else cout << "No" << endl;
       ```

     - 例 3，输出 `1`：

       ```cpp
       int n = 49;
       bool found = false;
       for (int i = 1; i * i <= n; i++) {
           if (i * i == n) {
               found = true;
               break;
           }
       }
       cout << found << endl;
       ```

  3. 易错点：
     - i 从 0 开始导致除以 0。

### 8.4 风险

- **学习记录挂错课**：
  - 现象：进度按路径记录（`src/utils/lessonProgress.js`，键是 `/lesson/1/N`）。内容重排后，旧的“已过关”会显示在新内容上。例如 `/lesson/1/5` 原来是“字符与真假值”，改后是“赋值与自增自减”，学生没学过新内容却显示已过关。
  - 处理：由用户决定。可选方案有三个：
    - 发布说明里提示一级进度会重置；
    - 给 L1 进度键加内容版本号；
    - 只在第 4、8、12 课的诊断节点重新判定。
- **教师讲义失效**：引用“第 N 课讲 X”的讲义、截图、外部链接会对不上，发布时需要一张旧课到新课的对照表（即 §3 表的旧课名列）。
- **批次期间新旧混排**：按“每批 2–4 课”推进时，中间版本会出现新旧课序混排。建议先改 3、4（两课对调），再改 5、6（新课），然后 7–9，最后 10–16。每批都保证前后课 `nextReason` 文案能对上。
- **◇ 卷题源**：课堂练习大量使用 ◇ 卷。若日后核实某题与官方不符，只需改标签，不影响主线，因为真题页都用 ✅ 题。
- **教学效果**：本方案只完成内容与考点对照，教学效果待试学验证。
