# C++ 课程与 GESP 上机训练

这次加入 44 道原创课堂上机题，采用“课内读题、学生本机编程、样例与边界验收、阶段真题迁移”的方式。一级每课一题，二至八级各四道关键节点练习。课程首页的“上机与备考路线”可以直接进入相应课次的上机题。

## 课堂怎么用

1. 学完本课知识点，让学生先口述输入、处理、输出，并手算一组样例。
2. 学生新建 `.cpp` 文件独立编程；先不展开提示和参考实现。
3. 核对样例，再根据题目要求补一组边界数据。不要在程序输出中添加提示语。
4. 交付源代码、运行结果、边界数据与结果，以及一句错因复盘。
5. 达到题目所列前置学习节点后，再进入原题与阶段综合卷。先独立完成，再阅读解析；错因归入读题、算法、边界、格式，再回课内补练。

页面上的勾选是学生自查，保存在当前浏览器，不作为在线判题结果，也不自动授予课程掌握状态。真题提交使用洛谷入口；本网站未新增在线编译服务。

## 内容与验收

- 每题包含题面、输入输出格式、数据范围、思路提示、边界要求和折叠参考实现。
- 43 道输入题各有两组样例；第一课为固定输出任务，提供一组无输入样例，共 87 组。
- 学生可下载不含答案的 Markdown 题目单；参考实现采用 C++17，并优先使用本课已学方法。
- 真题入口来自项目现有题库，与题号、题名和所属试卷交叉验证。原题与课堂题的格式、范围可能不同，迁移前须重新读题。
- 可运行 `node scripts/validate-cpp-practice.mjs` 编译所有参考程序并逐一验证样例，需要本机 C++17 编译器。
- 运行开发服务后，用 `CPP_PRACTICE_BASE_URL=http://127.0.0.1:4187 node scripts/check-cpp-practice-ui.mjs` 检查课次入口、首页路线、移动布局、折叠答案、题单下载和自查记录。

新增题目统一维护在 `src/data/cppProgrammingPractice.js`，无需逐个修改课程页面。新增节点时要同步检查前置知识、边界样例和真题迁移说明。
