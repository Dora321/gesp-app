## 推荐补题路径

1. 先从官方真题页面拿到对应 PDF 链接
2. 用 `pypdf` 提取可读文本
3. 对缺失的代码截图题：
   - 优先找公开解析页
   - 再找洛谷/博客园/CSDN 的题号映射
4. 统一写入 `src/data/gesp/level3/YYYY-MM-l3.js`
5. 每补一套都跑一次 `npm run build`
