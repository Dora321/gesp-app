# 单选题答案审计报告（对照官方 PDF 答案表）

生成日期：2026-07-19　工具：`npm run audit:answers`

## 方法

官方真题 PDF 第 1 页印有单选题「题号 / 答案」表。工具下载每卷 PDF、提取该表，与题库答案逐题比对。
判定不是比字母，而是比**答案指向的选项文本**——同一批选项换个顺序时，「题库 A / 官方 C」并不构成错误。

判定分四类：

| 类别 | 含义 | 处理 |
|---|---|---|
| ANSWER-WRONG | 题干选项一致，答案指向的内容不同 | 按官方答案表更正 |
| NOT-OFFICIAL | 题库该题与原卷同题号题目不同 | 标记 sourceIntegrity，不改答案 |
| reordered | 答案内容相同，仅选项顺序不同 | 无需处理 |
| UNDETERMINED | PDF 选项无法可靠提取 | 待人工核对 |

## 结果

- 已审计：81 / 92 卷，比对 1215 个单选答案
- ANSWER-WRONG：1（已全部处理）
- NOT-OFFICIAL：64 题（已标记）
- reordered（良性）：4
- UNDETERMINED：5
- 未能审计：11 卷（PDF 无可提取的答案表）
