# 单选题答案审计与原卷回填报告

生成日期：2026-07-19　工具：`npm run audit:answers` / `node scripts/backfill-from-pdf.mjs <卷号> [--apply]`

## 方法

官方真题 PDF 第 1 页印有单选题「题号 / 答案」表。审计工具下载每卷 PDF、提取该表，与题库答案逐题比对。
判定不是比字母，而是比**答案指向的选项文本**——同一批选项换个顺序时，「题库 A / 官方 C」并不构成错误。
若选项集相同但题干不同，则判为「题目非原卷」而不是答案错误：此时按官方答案表改答案，反而会把本来自洽的题改错。

回填工具再从 PDF 提取原卷题干与选项，替换那些被判为非原卷的题。两条硬约束：

- **提取错位即拒绝**：若任一选项仍带 `B. ` 这样的字母前缀，说明 PDF 选项行的切分没跟上版式，该题直接跳过，不写入。
- **代码是图片就如实标注**：多数卷的代码清单在 PDF 里是图片、无文本层，这类题回填题干/选项/答案后仍标记 `missing-figure`，不伪装成完整题目。

## 结果

| 指标 | 回填前 | 回填后 |
|---|---|---|
| 答案错误（ANSWER-WRONG） | 3 | **0** |
| 题目非原卷（NOT-OFFICIAL） | 65 | **9** |
| 选项换序（良性） | 4 | 4 |
| 无法判定（UNDETERMINED） | 5 | 5 |

- 已审计 81 / 92 卷，比对 1215 个单选答案。
- **56 道题已用官方原卷题干与选项回填**，其中一部分恢复为可独立作答的完整题目，其余因代码是图片而标记 `missing-figure`。
