## 3. 分级内容安排

先沿用每级 16 课的结构。正式调序以考纲映射和前置知识审计为依据；如需移动内容，同步设计旧链接和学习记录的兼容方式。

| 阶段与现有课次 | 内容升级重点 | 学生可验收的产出 |
| --- | --- | --- |
| L1 1～4 | 程序结构、输入输出、变量、整数与小数、整除取余；把生活描述翻译成表达式 | 独立完成输入—计算—输出程序，解释类型与计算结果 |
| L1 5～8 | 字符、逻辑、分支；用反例讲链式比较、边界归属和条件顺序 | 门票或成绩分类程序，附临界值测试表 |
| L1 9～12 | 循环执行顺序、累加与计数、停止条件、break/continue；核定嵌套循环的拓展定位 | 循环跟踪表，能解释最后一轮与结束状态 |
| L1 13～16 | 数学条件、简单模拟、筛选统计与综合复盘 | 独立完成综合题，提交测试与错因说明 |
| L2 1～4 | 存储与网络、字符转换、类型转换、switch；先测再补 L1 基础 | 存储/网络说明任务，以及转换、菜单分支程序 |
| L2 5～8 | 嵌套循环、图形、流程图和数学函数；建立行列与状态模型 | 行号—空格—符号数量表，流程图与代码互译 |
| L2 9～12 | 质数、数位、因数倍数；核定数组初探的衔接定位 | 能处理 0、1、平方数和末尾 0 等边界的程序 |
| L2 13～16 | 多步模拟、调试、综合训练 | 状态表、独立程序、失败用例与修复解释 |
| L3 1～4 | 进制、固定宽度补码、位运算；区分表示模型与 C++ 运算规则 | 进制推导、位变化表和掩码练习，注明位宽与范围 |
| L3 5～9 | 数组、字符串和综合；突出初始化、下标、遍历和输入边界 | 统计、查找、字符处理程序，附越界与空输入条件分析 |
| L3 10～12 | 枚举、模拟、加密；说明候选范围、检查条件和更新顺序 | 能解释不遗漏、不重复的枚举或模拟方案 |
| L3 13～16 | 图形综合、进制编程、逻辑挑战与模拟测评 | 完成从读题、建模、编码到验收的全过程 |

跨级递进应写入目标：例如 L1 的字符课侧重字符与编码差值，L2 侧重字符分类与转换，L3 侧重字符串遍历与统计；循环从读懂单层执行，进阶到嵌套建模，再到数组遍历和枚举。

## 4. 每课统一的教学要求

每课建议围绕 2～3 个可验证目标组织内容。教学环节按概念性质调整，不机械填满页面。

1. 前置诊断：2～3 个短任务；错误指向具体先修内容。
2. 问题导入：一个明确问题，让学生先预测结果或提出方案。
3. 概念讲解：生活例子、精确定义、适用范围和反例相互对应。
4. 执行观察：展示代码、变量或数据结构、输出的对应变化。
5. 引导练习：从补关键步骤过渡到完整解决，提示逐层展开。
6. 独立任务：代码课至少 1 道上机任务；通识课采用分类、解释或操作任务。
7. 变式与挑战：基础题更换条件后再练；挑战题标明拓展与前置知识。
8. 出门检测：一道新情境任务和一句解释，生成具体复习建议。

每道编程任务包含：题意、输入输出、范围、样例、分层提示、可编译参考实现、边界测试及常见错误解释。错误程序须清楚标注，不能作为可直接使用的参考代码。

每级在第 4、8、12 课后安排短诊断，第 16 课完成综合测评，共 12 个阶段节点。原创诊断与官方真题明确标识；自编综合测评不默认宣称符合官方全真考试规格。

## 6. 验收标准

| 维度 | 验收要求 |
| --- | --- |
| 内容正确 | 48 课逐课核查；已发现 P0 错误清零；定义、示例、答案与范围一致 |
| 知识递进 | 每课有先修要求；新语法先讲后用；拓展明确标注 |
| 编程可靠 | 认证相关参考实现按默认 C++11 编译并运行样例和适用边界；项目使用更高标准的练习另行标注 |
| 练习覆盖 | 48 课均有与目标一致的独立任务；编程课有上机训练，通识课有等价产出 |
| 学习反馈 | 每个核心目标有对应检测；答案适时揭示；尝试、自查与验证结果能区分 |
| 阶段评估 | 12 个阶段节点都有题目、答案、评价规则与回学建议 |
| 页面体验 | 桌面与手机可操作；代码长行可滚动；交互有键盘焦点与明确标签 |
| 回归检查 | 课程流程、内部链接、相关测试与构建通过；共享组件修改检查其他等级 |
| 教学有效性 | 样板课先做教学走查；有真实试学条件后收集完成率、典型错因和提示使用情况，再调整难度 |
