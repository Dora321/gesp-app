## 1. 一句话主线

L1–L8 是一条“**写对程序 → 拆对题目 → 组织数据 → 设计算法**”的 GESP C++ 备考线。每一级只在上一级已经能独立完成的程序上，增加一种数据组织方式或一种解题方法，并用站内真题验收。

| 阶段 | 级别 | 学生要证明的能力 |
| --- | --- | --- |
| 写对程序 | L1 | 程序能编译、能运行，输出与样例逐字一致；能用输入、分支、单层循环控制程序 |
| 拆对题目 | L2 | 能把一道题拆成循环层次、状态变化和输出格式 |
| 组织数据 | L3–L4 | 能用数组、字符串、函数和结构体保存并处理一批数据 |
| 设计算法 | L5–L8 | 能按数据范围选择算法，并解释正确性与复杂度 |

## 3. 语气规范

受众是小学 3–6 年级的 GESP C++ 备考学生。主调是**备考课**：清晰、可考、有挑战感。每一节都应回答三个问题：考什么、怎么判断、错在哪。

### 3.1 禁用的词与风格

| 类别 | 例子 | 改成 |
| --- | --- | --- |
| 魔法、奇幻 | 魔法、魔术师、咒语、召唤、魔法工坊、神奇、奥秘、秘密 | 直接写能力名，如“程序结构拆解” |
| 外星、童话角色 | 外星生物、小精灵、怪兽 | 删除 |
| 侦探、警匪 | 侦探社、卧底、抓坏蛋、火眼金睛、👮 | “纠错练习”“找出不合法的变量名” |
| 器官拟人 | 眼耳口鼻、肚子、嘴巴、计算机“吃/吐”东西、“憋死” | 信息流动方向、部件名称、编译器行为 |
| 与编程无关的生活包装 | 乱糟糟的书包、房子/大管家/租客 | 用一个编程问题导入，例如“数量变了要改代码吗” |
| 夸奖式反馈 | 小天才、太棒了 🎉 | “回答正确。”加依据；“回答错误，正确答案是 X。”加解析 |
| 装饰性 emoji | 标题和大图里的 🦖 👴 🏠 👽 | lucide 图标或不用 |
| 未核实断言 | 必考、高频、真题最爱 | 只写可核实的出处 |

### 3.2 允许的比喻

比喻要少，要贴合编程，并且紧跟精确定义。

- 变量：内存中带名字的存储格子（也可说“带名字的数据盒子”）。
- 数组：一排从 0 开始编号的格子。
- `cout <<` 把数据送向屏幕，`cin >>` 把数据送进变量（方向记法）。
- 函数：给定输入、返回结果的加工步骤。
- 栈、队列：一摞盘子、排队（经典计算机比喻）。

规则：每节最多一个比喻；比喻后立即给定义和适用范围或反例；判题依据只能是定义，不能是比喻。

### 3.3 标题命名原则

- **课名**：`第 N 课：<考纲能力名>`，例如“第 9 课：for 循环”。英文术语可以括注；不用比喻做主标题；尽量在 12 个字以内。
- **节名**：`<环节>：<内容>`。环节词固定为：热身 / 问题导入、`真题：YYYY 年 M 月一级第 N 题`、课堂练习、`上机：<题名>`、常见错误与真题、小结与课后任务、离开前检查。
- **分类（侧栏 category）**：用能力段名，如“计算机基础”“第一个 C++ 程序”“命名规则”。
- **题源标签**：`YYYY 年 M 月 GESP 一级第 N 题`；判断题写`判断题第 N 题`（站内题库序号 16–25 对应判断题第 1–10 题）。

## 4. L1–L8：每级 focus 与级间 bridge

下表按**站内现有课名**归纳，不等于官方考纲等级认定。批量改造某一级之前，须先对照 [CCF GESP 认证标准](https://gesp.ccf.org.cn/101/attach/1725701770182688.pdf) 逐项核对。

| 级 | 本级 focus（一句） | bridge：进入下一级的条件 |
| --- | --- | --- |
| L1 | 写对程序：输入输出、变量与常量、基本类型、算术与逻辑表达式、if/switch、for/while，能独立完成“输入—计算—输出”题 | 单层循环和条件能手推次数与边界后，二级把它们嵌套起来拆题 |
| L2 | 拆对题目：存储与网络、ASCII 与类型转换、嵌套循环与图形、流程图、数学函数、质数/数位/因数、多步模拟 | 能逐步模拟“单个数”的变化后，三级开始处理“一批数据”和数据的二进制表示 |
| L3 | 线性数据：进制与补码、位运算、一维数组、`string`、枚举与模拟 | 程序变长、数据变多后，需要拆分成函数并用结构描述数据 |
| L4 | 模块化：函数与参数传递、递归入门、指针入门、结构体、二维数组、三种基础排序、递推、文件重定向 | 会写模板后，五级开始比较算法效率 |
| L5 | 算法效率：筛法、GCD、高精度、链表、二分、分治、贪心、记忆化、复杂度 | 线性结构与经典算法稳定后，进入树、搜索和动态规划 |
| L6 | 树与搜索：树与哈夫曼、BFS/DFS、类与继承多态、格雷码、DP 基础与背包 | 能写单一搜索或 DP 模板后，七级要求组合、剪枝和更复杂的结构 |
| L7 | 进阶结构与 DP：二叉排序树、哈希、图的存储、搜索剪枝与判重、线性 DP 与背包家族、命名空间、排序稳定性 | 搜索与 DP 能解释状态后，八级进入图论算法和组合数学 |
| L8 | 图论与组合：计数与组合数、概率期望、运算符重载与模板、最短路、最小生成树、区间/树形 DP、快速幂、复杂度 | 主线完成后，回到真题库做跨级整卷复盘 |

**发现的不一致（待批量改造时处理）：**

- `src/data/cppLevelFlow.js` 的 5–8 级 focus 与课名不符：五级写了“二维数组、字符串成员函数”（二维数组在 L4-8）；六级写了“指针、高精度、贪心”（分别在 L4、L5），却没写六级课名里的树、搜索和 DP；八级写了课名中没有的“拓扑排序”。
- L6 与 L7 重复：BFS/DFS（L6-4、5 与 L7-6、7）、类与继承（L6-6～8 与 L7-11、12）、背包（L6-12、13 与 L7-10）。重访时必须写明新增能力，否则应合并。
