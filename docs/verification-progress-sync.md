# 核验证据与网站进度同步

2026-10-25：修复首页、题库列表、题目页之间的核验状态脱节。

## 统计口径

- 卷级“完整”必须五项全部完成：题面、选项、答案、解析、参考代码。
- 选项适用单选题；答案适用客观题；参考代码适用编程题。样例运行通过不等于参考代码已完整核验。
- 保留历史卷级标签供旧接口兼容，但展示和汇总统一读取生成的 `verification.dimensions`，不再依据旧的 `reviewStatus` 声称完整核验。
- “已有核验进展”包含历史有范围声明的校订和已登记的逐题证据，不代表卷内每道题都核完。未知维度保留未核验。

## 证据接入与保守边界

注册表生成器在构建时读取 `docs/question-bank-verification/<paperId>.json`，不将整份文档打包到首屏。

1. 文档 paperId 必须一致，必须记载 `shaVerified: true`，镜像 SHA 必须与来源登记匹配。
2. 识别完整结构化答案表与逐题官方答案，逐项与运行时答案比较。冲突保留，不自动修改答案。截断表不推测缺失项。
3. 接入 `resolved: true` 的显式维度清单、`textMatch: true` 的题面核对，以及明确的整卷转写重建报告。不会用“修改过”或一段无结构说明推定全部维度通过。
4. “代码题已校订”属于题面进展，不等于编程题参考代码核验。整卷重录也不自动算作解析核验。
5. 保留的 `sourceIntegrity` / `needsReview` 优先；有未决项或来源答案冲突的记录不能把相关卷直接升级为完整。
6. 历史声明没有逐题编号时只保留其明确范围；未知逐题覆盖数量不伪造。文档尚未结构化的自由文字不会自动转换为“已核验”，审题组可补充明确的逐题维度与证据。

此次只同步已有证据和状态，不构成重新审题，也不修改题面、选项、答案、争议标记或审题组原始记录。
