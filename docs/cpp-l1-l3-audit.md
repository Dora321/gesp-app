# C++ L1～L3 课程基线审计

核验日期：2026-09-20。依据：[CCF GESP C++&Python 认证标准](https://gesp.ccf.org.cn/101/attach/1725701770182688.pdf) 与 [2026 年修订说明](https://gesp.ccf.org.cn/101/1002/10255.html)。

这是**逐课范围与教学结构初筛**，不是 48 课逐行内容、代码、题源与答案的最终验收。课名来自当前课程目录；“定位”指教学安排，不代表该整课都是官方同级必考内容。需要继续查证的地方保留为待办，不推断已通过。

首次静态结构扫描：48 课均有 `MasteryCheck`；L1 有 2 课使用 `PredictCheck`，L2 有 12 课，L3 有 14 课。初筛时独立上机题覆盖 L1 16/16、L2 4/16、L3 4/16；本轮已补齐为三级均 16/16。`MiniQuiz` 当前直接显示答案，应作为复习卡，不计入独立测评成绩。课程流程检查已通过。
