# C++ L1～L3 课程基线审计

核验日期：2026-09-20。依据：[CCF GESP C++&Python 认证标准](https://gesp.ccf.org.cn/101/attach/1725701770182688.pdf) 与 [2026 年修订说明](https://gesp.ccf.org.cn/101/1002/10255.html)。

这是**逐课范围与教学结构初筛**，不是 48 课逐行内容、代码、题源与答案的最终验收。课名来自当前课程目录；“定位”指教学安排，不代表该整课都是官方同级必考内容。需要继续查证的地方保留为待办，不推断已通过。

首次静态结构扫描：48 课均有 `MasteryCheck`；L1 有 2 课使用 `PredictCheck`，L2 有 12 课，L3 有 14 课。初筛时独立上机题覆盖 L1 16/16、L2 4/16、L3 4/16；本轮已补齐为三级均 16/16。`MiniQuiz` 当前直接显示答案，应作为复习卡，不计入独立测评成绩。课程流程检查已通过。

| C05 | 二级第 12～16 课多处把数组写成二级核心或高频考点，官方列在三级 | 已把二级数组课、综合模拟和结课清单明确标为三级前瞻；三级第 5 课承担正式学习与独立检测 |
| C06 | 三级标准包含数组、字符串、算法描述、枚举与模拟；课程总览还需逐项核对。认证知识体系中出现函数使用，当前独立函数教学在四级 | 已在 L3-12 补函数定义、调用、形参与实参、返回值的入门说明；四级保留深入讲解。三级算法描述仍待补核 |
| C07 | 2026 修订明确三级一维数组不包括变长数组 | 三级数组示例使用编译期容量并核对实际长度；检查其他课是否出现 `int a[n]` |
| C08 | 学习证据规则原把“尝试”和“正确作答”都视为完成证据 | 已区分尝试、答对、自查和提交产出；L1～L3 单纯尝试不再完成离课检查，自查与产出均标明未自动判题 |
| C09 | L1-9 检查项误写 `for` 有三个分号；L2-9 把 `i*i<=n`称为整数安全 | 已在样板中修订，并纳入同类表述扫描 |
| C10 | L2-8 原用 `sqrt(25)` 推断可能截断成 4，例子本身不成立 | 已改为 `sqrt(15)` 的确定性截断示例，并同步修正预测题与掌握检查 |
| C11 | L3-2 将 8 位补码手算的 `127+1→-128` 与 C++ 有符号整数溢出混同 | 已限定为“只保留低 8 位”的手算模型，补充 C++ 整数提升及有符号溢出不可依赖的说明；依据 [C++11 工作草案 N3337](https://open-std.org/JTC1/SC22/WG21/docs/papers/2012/n3337.pdf) |
| C12 | L3-4 把 `cout << x << 1` 解释为“移位优先级低于流插入”，L3-3 用掩码 4 输出“第 3 位” | 已按 `<<` 从左到右结合的规则修正讲解，并将掩码 4 标为从 0 数的第 2 位；依据 [C++11 工作草案 N3337](https://open-std.org/JTC1/SC22/WG21/docs/papers/2012/n3337.pdf) 第 5.8 节 |
| C13 | L1-2 的独立题已使用 `cin`，但对应课页没有读入教学；L1-3 要求尚未讲的数位拆解，并误称下一课为输入输出课 | 已在 L1-2 加入 `cin` 最小示例和可键盘操作的测验选项；L1-3 改为同一知识的三人平均分变式，补一位小数格式输出说明并修正衔接 |
| C14 | L1-4 把 `n % 2 == 1` 当作所有整数的奇数条件，数位演示接受负数却按 JavaScript `Math.floor` 计算 | 奇数统一用 `n % 2 != 0`；数位演示限定三位正整数并在无效输入时暂停结果展示；补除数非零的前提 |
| C15 | L1-5 把 ASCII 编码与大小写转换当成一级离课必会内容，并将 `'AB'` 一概说成语法错误 | 核心目标改为 `char` 读入与原样输出、字符与字符串区分、`bool` 输出；ASCII 与字符运算明确为二级前瞻。多字符普通字符字面量的值由实现决定，不能当作通用语法错误；依据 [C++11 工作草案 N3337](https://www.open-std.org/jtc1/sc22/wg21/docs/papers/2012/n3337.pdf) 第 2.14.3 节 |
| C16 | L1-6 未示范 `&&`/`||` 的短路求值，并笼统宣称先算术后逻辑，容易误解 `!` 的优先级 | 补可执行的短路示例与离课预测题；优先级改为对具体表达式逐项分析，并明确 `!` 的位置不能用“算术后逻辑”概括 |
