## 三、逐题详述

### 1. `2023-12-l5` 第 5 题（单选，2 分）

**现状**：`sourceIntegrity: official-source-defect`，`integrityNote` 为「原卷命中尾结点时直接解引用 p->next，可能空指针访问。保留填空答案 B 并注明原程序边界缺陷。」站点 `answer: 1`（B），解析已说明答案 B 与原程序边界缺陷。

**原卷依据**

- 题干页：`page-03.jpg`（PDF 第 3 页）。逐字题干：「下面的 C++ 代码用于将字符串保存到带头节点的双向链表中，并对重复的串计数，然后将最新访问的串的节点放在链头便于查找。横线处应填入代码是（ ）。」
- 原卷代码（第 1–28 行）关键段：

```cpp
Node *Insert(Node *pHead, string s)
{
    Node *p = pHead->next;
    Node *q;
    while (p) {
        if (p->str == s) {
            p->ref++;
            p->next->prev = p->prev;
            p->prev->next = p->next;
            break;
        }
        p = p->next;
    }
    if (!p) {
        p = new Node;
        p->str = s;
        p->ref = 0;
        p->next = p->prev = NULL;
    }
    __________________________________________
    pHead->next = p, p->prev = pHead;
    return pHead;
}
```

- 原卷选项（逐字，注意原卷用的是逗号表达式）：
  - A. `if(pHead) {p->next = pHead->next, pHead->next->prev = p;}`
  - B. `if(pHead->next) {p->next = pHead->next, pHead->next->prev = p;}`
  - C. `p->next = pHead->next, pHead->next->prev = p;`
  - D. `触发异常，不能对空指针进行操作。`
- **官方答案表**：`page-01.jpg`（PDF 第 1 页）单选答案表第 5 列印作 **B**。同表 15 列为 `C C D A B A C B D B D B B C B`，第 5 位确为 B。

**独立推导**

带哨兵头结点 `pHead`。横线位于「找到重复结点 `p`（或新建结点）」之后、「`pHead->next = p`」之前，要做的是把 `p` 头插到哨兵之后。

- **空链表**：`pHead->next == NULL`，`p` 是刚 `new` 出来的结点，`p->next = NULL`。
  - A 的条件 `if (pHead)` 恒真，执行 `pHead->next->prev = p`，即对 `NULL->prev` 写入 → 空指针访问。
  - C 没有条件，直接 `pHead->next->prev = p` → 同样空指针访问。
  - B 的条件 `if (pHead->next)` 为假，跳过；随后 `pHead->next = p; p->prev = pHead;`，`p->next` 保持 `NULL` → 正确。
- **非空链表**：B 先令 `p->next = 旧首结点`、`旧首结点->prev = p`，再令 `pHead->next = p`、`p->prev = pHead` → 正确头插。
- 因而 B 是四个选项中**唯一**能同时处理空表和非空表的写法。

**本机实测**（Apple clang 21.0.0，macOS arm64；用 `g++` 驱动，`-fsanitize=address`）：

```text
OPTION=A（原卷 A）
  empty : AddressSanitizer: SEGV q5_clean.cpp:22  // pHead->next->prev = p
  middle: 同左（第一次插入空表时即崩溃）
  tail  : 同左
OPTION=B（原卷 B）
  empty : empty insert A: A
  middle: middle re-access B: B C A
  tail  : AddressSanitizer: SEGV q5_clean.cpp:10  // p->next->prev，p 为尾结点
OPTION=C（原卷 C）
  empty : AddressSanitizer: SEGV q5_clean.cpp:26  // pHead->next->prev = p
  middle: 同左
  tail  : 同左
```

这说明：

1. A、C 连空表都过不了，B 唯一正确；
2. B 的 `tail` 场景崩溃，崩溃点在**横线之前的重复结点摘链代码**（`p->next->prev = p->prev`），不在横线处；这是原程序另一个边界缺陷，不影响「横线填 B」的唯一性。

**争议根因**

原卷代码在「命中重复串且该结点是尾结点」时，`p->next == NULL`，却直接执行 `p->next->prev`，会空指针访问。缺陷在横线之前，属于「考点外瑕疵」；填空本身仍有唯一解 B。站点标记 `official-source-defect` 事实正确，但按历史语义该标记会自动排除计分，导致一道可答题被误排除。

另有一条**非实质性**的忠实度差异：站点把原卷的逗号表达式（`p->next = pHead->next, pHead->next->prev = p;`）改写成了分号两条语句；两者语义等价，不影响答案。若追求逐字忠实，可恢复逗号，但不建议为此单独改题。

**裁决选项**

- **A. 维持原卷答案 B，解析加注「尾结点删除缺判空」，本题正常计分。**
- B. 保留 B 与原缺陷标记，`examScoring: excluded`，继续不计分。
- C. 清掉争议标记、按普通题处理（答案仍为 B），不保留任何缺陷注记。

**推荐：A。** 理由：B 是唯一能处理空表的选项，考生按命题意图可以正常作答；缺陷落在横线之外，符合「考点外瑕疵」的定义。建议字段（未落地）：`sourceIntegrity: official-source-defect`、`defectKind: out-of-scope`、`examScoring: counted`、`integrityNote` 保留尾结点说明。注意校验规则要求 `out-of-scope` 必须配 `counted`，不能填 `ub` 后仍计分。

### 3. `2023-09-l6` 第 5 题（单选，2 分）

**原卷依据**

- 题干页：`page-02.jpg`（PDF 第 2 页）。逐字题干：「有关下面 C++ 代码的说法，错误的是（ ）。」
- 代码（原卷第 1–15 行）：

```cpp
#include <iostream>
#include <string>
using namespace std;

class MyStr {
    string data;
public:
    MyStr(string _data): data(_data) {}
};

int main() {
    MyStr st("ABC");

```

- 选项：
  - A. 代码 `cout << st << endl;` 会报错，因为没有为 `MyStr` 类重载 `<<` 运算符。
  - B. 第 6 行代码的 `data` 是 `MyStr` 类的成员变量。
  - C. 代码 `MyStr st("ABC");` 不会报错，将执行构造函数。

- **官方答案表**：`page-01.jpg`（PDF 第 1 页）单选答案表第 5 列印作 **A**。同表 15 列为 `A D D D A D D B B B B C C B D`。

**独立推导**

- A：`MyStr` 没有 `operator<<`，`cout << st` 一定编译失败。A 的说法**为真**。
- B：`data` 是 `class MyStr` 的成员（第 6 行），**为真**。

**争议根因**

**独立推导**

设 32 人中，综合成绩最后 4 人为集合 B（|B|=4），其余 28 人为集合 G。

- 班长：不能来自 B，28 种；
- 学习委员：不能来自 B，且不能与班长同一人，27 种；

- 组织委员：剩 29 人，29 种。

总数

`28 × 27 × 30 × 29 = 657,720`。

而

`P(30,4) = 30 × 29 × 28 × 27 = 657,720`。

两者完全相等——不是「巧合误差」，而是**同一组因子的不同顺序**：限制后 4 名不能当班长/学习委员后，剩下的人数正好是 30、29、28、27，恰好等于 `P(30,4)` 的四个因子。更一般地，对 n 名学生、后 4 名不得担任 2 个指定职务，方案数为

`(n−4)(n−5)(n−2)(n−3) = P(n−2,4)`。

```text
actual=657720
P(30,4)=657720
C(32,4)=35960
P(32,4)=863040
28*27*30*29=657720
```

**裁决选项**

- A. 保留 0 与缺陷标记，加注「官方 √、实际也 √」（标记本身是假的，不应保留）。
- B. 保留 0、排除计分（浪费一道好题）。

**推荐：C。** 理由：

1. 官方答案表第 10 列确为 √，站点答案 0 也是 √，二者一致；
2. 穷举验证 657,720 = P(30,4)，命题为真；

建议字段（未落地）：`answer: 0` 不变；删除 `sourceIntegrity` / `integrityNote`；`explanation` 重写为「四个角色分别有 28、27、30、29 种选择，总数 657720；P(30,4)=30×29×28×27=657720，二者相等（因子相同、顺序不同），命题正确」。
