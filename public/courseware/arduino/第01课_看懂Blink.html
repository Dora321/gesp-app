写在哪

每一行的 // 后面

两人商量着说，检查员写在任务卡上，操作手敲进电脑。原来的英文注释可以删掉，换成你的话。

小心输入法

中文只写在 // 后面

打中文时，; 会变成 ；，( 会变成 （。代码部分只用英文符号。

写完再上传一次：灯的样子一点都不能变——变了，说明你动到了 // 前面的代码。

「最后一步，写。给 9 行代码每一行写一句中文注释。前两行我示范了，剩下 7 行归你们。」

「怎么写？用自己的话说这一行在干什么，不用逐字翻译英文。两个人商量着说，检查员写在任务卡第③栏，操作手敲进电脑。」

「最容易出的错：切到中文输入法写注释，写完忘了切回来，分号就变成了中文的分号，括号变成中文括号，一上传就是一片红字。所以：中文只写在两个斜杠后面。」

「写完再上传一次，灯的样子一点都不能变。变了，说明你不小心动到了 // 前面的代码。」

（真有组撞上 stray '\357' 的红字，别急着帮忙改：让学生读出报错的行号，自己找到那个中文符号。这正好是第 2 课的内容。）
