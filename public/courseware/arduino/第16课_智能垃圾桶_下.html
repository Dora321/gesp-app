loop：三件事，谁也不等谁millis 版
void loop() {
  if (readDistance() < 20) {              // 有人：开盖，重新计时
    lid.write(90);
    lidOpen = 1;
    since = millis();
  }
  if (lidOpen == 1 && millis() - since >= 3000) {   // 3 秒没人：关
    lid.write(0);
    lidOpen = 0;
    digitalWrite(GREEN, LOW);
    delay(1000);                          // 冷却
  }
  if (lidOpen == 1 && millis() - lastBlink >= 250) { // 开着：灯每 0.25 秒换一次
    lastBlink = millis();
    led = 1 - led;
    digitalWrite(GREEN, led);
  }
  delay(50);
}

有人：开盖，重新计时

since = millis(); 记下这一刻。

②

3 秒没人：关

现在 − since ≥ 3000。

③

开着：灯每 0.25 秒换一次

现在 − lastBlink ≥ 250。
