void setup() {
  Serial.begin(9600);

void loop() {
  Serial.println(count);
  if (count == 0) {                  // 数到 0 了吗？
    digitalWrite(LED_BUILTIN, HIGH); // 到 0：亮灯，停在 0
  } else {
    count--;                         // 没到 0：减 1，接着数
  }

到 0 了吗？

到了做上面的大括号，没到做 else 下面的。下节课细讲。

== 和 =

两个等号是「比较」

count == 0 问「是不是 0」；一个 = 是放进去。

改一改：从 5 倒数？到 0 时三个灯都亮（上节课的交通灯模块）？

（★★★ 的组做的时候开着这一页。）

「注意 if 里面是两个等号：count == 0 是在问『count 是不是 0』；一个等号是『放进去』。写成一个等号，意思就全变了。」

「到 0 以后为什么停住了？因为到 0 就不再减 1 了，每秒都打印 0。」
