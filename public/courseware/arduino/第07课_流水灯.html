★★ 流过去，再流回来：pin--

loop：两个 for12 行
void loop() {
  for (int pin = 5; pin <= 10; pin++) {    // 5 → 10
    digitalWrite(pin, HIGH);
    delay(200);
    digitalWrite(pin, LOW);
  }
  for (int pin = 10; pin >= 5; pin--) {    // 10 → 5：流回来
    digitalWrite(pin, HIGH);
    delay(200);
    digitalWrite(pin, LOW);
  }
}

到几为止，怎么写？

pin >= 5：大于等于 5。数到 5 还亮，变成 4 才停。

？ 先自己想
两头的灯会连着亮两次（10 号和 5 号）——想想为什么？能改掉吗？

（★★ 的组做的时候开着这一页。）

「第一个 for 不动：5 流到 10。下面再写一个 for，倒着数：从 10 开始，每次 pin--，减 1。」

「到几为止怎么写？」→ 揭晓「pin >= 5：大于等于 5。数到 5 还亮，变成 4 才停。」

「做出来以后仔细看：10 号和 5 号会连着亮两次。为什么？第一个 for 最后亮的是 10，第二个 for 第一个亮的又是 10。想改掉的话，第二个 for 从 9 开始、到 6 为止就行。」

★★★ 号码不连续：用数组排成一队

array.ino16 行
// B 模块改插 12、4、2 号：号码不连续，用数组排成一队
int pins[6] = {10, 9, 8, 12, 4, 2};

void setup() {
  for (int i = 0; i < 6; i++) {    // i 是第几个：0～5
    pinMode(pins[i], OUTPUT);
  }
}

void loop() {
  for (int i = 0; i < 6; i++) {
    digitalWrite(pins[i], HIGH);
    delay(200);
    digitalWrite(pins[i], LOW);
  }
}
数组的编号从 0 开始：6 个号码，编号是 0～5，所以 for 写 i < 6。

（★★★ 的组做的时候开着这一页。）

「先把 B 模块的 R、Y、G 拔下来，改插 12、4、2 号，GND 不动。现在 6 个灯是 10、9、8、12、4、2——号码不连续，没法用 pin++ 一个一个数。」

「数组就是一排带编号的盒子。第 2 行：做一排 6 个盒子，名字叫 pins，里面依次放 10、9、8、12、4、2。」

「最要紧的一点：编号从 0 开始。pins[0] 是 10，pins[5] 是 2。所以 for 里 i 从 0 数到 5，写成 i < 6。」

「每一遍用 pins[i] 代替原来的 pin——第 i 号盒子里装的引脚号。」（参考答案在教案资源 6。）
