loop 里的 if（填空）填空
  if (digitalRead(BTN) == LOW) {   // 按了一下
    if (on == 0) {                 // 现在是灭的
      digitalWrite(RED, ______);
      on = ______;
    } else {                       // 现在是亮的
      ______________________________
      ______________________________
    }
    delay(20);
    while (digitalRead(BTN) == LOW) { }   // 等松手

  }
先在 ② 变量区加一行 int on = 0;——0 是灭，1 是亮。 填空：HIGH、1；else 里：digitalWrite(RED, LOW); 和 on = 0;

（★★ 的组做的时候开着这一页。）

「台灯的开关：按一下亮，再按一下灭。板子怎么知道现在该开还是该关？——它得记住灯现在的样子。上一单元学的盒子就是干这个的：做一个盒子叫 on，0 是灭，1 是亮。」

「按了一下以后，问一句：on 是 0 吗？是——现在是灭的，那就开灯，再把 on 改成 1；不是——现在是亮的，那就关灯，把 on 改成 0。」

→ 揭晓「填空答案：HIGH、1；else 里两行，灭灯、on 改成 0。」

（常见错：忘了改 on——灯亮了就再也关不掉；等松手的 while 漏了——按一下灯来回闪好几次。）
