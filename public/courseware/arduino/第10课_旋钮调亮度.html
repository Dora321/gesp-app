★★ 打印电压：先乘还是先除，差别很大

loop：两种算法
void loop() {
  int raw = analogRead(KNOB);
  Serial.print(raw * 5.0 / 1023);   // 先乘 5.0
  Serial.print("    ");
  Serial.println(raw / 1023 * 5);   // 先除 1023
  delay(500);
}
串口监视器从左拧到右
0.00    0
1.25    0
2.50    0
3.75    0
5.00    5
raw / 1023：两个整数相除，小数被扔掉。 512 / 1023 = 0.5，扔掉小数 → 0，再乘 5 还是 0。先乘 5.0，整个式子就变成小数运算。

（★★ 的组做的时候开着这一页。）

「电压是 0 到 5 伏，所以 raw 乘 5、除以 1023 就是电压。两种写法：第 3 行先乘 5.0 再除；第 5 行先除 1023 再乘 5。看右边串口：第一列 0.00 到 5.00 跟着变，第二列几乎总是 0，拧到头才突然变成 5。」

「为什么？」→ 揭晓「C++ 里两个整数相除，小数部分直接扔掉。512 除以 1023 本来是 0.5，扔掉小数就是 0，再乘 5 还是 0。只有 raw 正好是 1023 时，1023 除 1023 等于 1。」

「第一种写 5.0，带了小数点，整个式子就变成带小数的运算，所以对了。」

（让学生在任务卡上写出 raw = 512 时两种算法的结果。）
