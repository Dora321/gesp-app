loop：旋钮调时长
void loop() {
  int cm = readDistance();
  if (cm < 20) {
    int raw = analogRead(KNOB);
    int openTime = map(raw, 0, 1023, 1000, 5000);   // 1～5 秒
    openLid();
    delay(openTime);
    closeLid();
    delay(1000);
  }
  delay(100);
}
两块积木（写在 loop 下面）
void openLid() {          // 开盖：转 90°、亮绿灯、嘀一声
  lid.write(90);
  digitalWrite(GREEN, HIGH);
  tone(BUZZ, 1000, 100);
}

void closeLid() {         // 关盖：转回 0°、灭灯
  lid.write(0);
  digitalWrite(GREEN, LOW);
}
上面加：GREEN = 8、BUZZ = 4、KNOB = A0 和两个 pinMode。map 换算成 1000～5000 毫秒。

（★★ 的组做的时候开着这一页。）

「右边两块积木：openLid——转 90 度、亮绿灯、嘀一声；closeLid——转回 0 度、灭灯。第 8 课的做法。」

「左边 loop：有人的时候，先读旋钮，用 map 换算成 1000 到 5000 毫秒——第 10 课的工具，这次换算成时间；然后开盖、等这么久、关盖、冷却。」

「上面别忘了加 GREEN、BUZZ、KNOB 三个名字和两个 pinMode。」
