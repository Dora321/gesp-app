第22课 A 端 20–40 分

A 端：按钮按下就发消息

五要素 · 只要 A 端：「请写代码：ESP32 连 WiFi 后连接 mqtt.bemfa.com 的 9501 端口，私钥当 client_id；GPIO14 接上拉按钮，按下（读到 0）就往主题 g1g2door01 publish 字符串 ding。约束：publish 传字符串不是字节，按完等 0.5 秒防连发，只用学过的写法。」
起步全码 · A 端（发送板）
import network, time
from machine import Pin
from umqtt.simple import MQTTClient
WIFI_SSID="你的WiFi名"; WIFI_PASS="你的WiFi密码"; KEY_A="A板私钥"
TOPIC = "g1g2door01"        # 两块板约好的主题
button = Pin(14, Pin.IN, Pin.PULL_UP)
wlan = network.WLAN(network.STA_IF); wlan.active(True)
wlan.connect(WIFI_SSID, WIFI_PASS)
while not wlan.isconnected(): time.sleep(0.5)
client = MQTTClient(KEY_A, "mqtt.bemfa.com", 9501); client.connect()
while True:
    if button.value() == 0:       # 按下=0（上拉）
        client.publish(TOPIC, "ding"); time.sleep(0.5)
    time.sleep(0.05)
time.sleep(0.5) 是防连发——手指按一下其实抖好几次，不加它云上会收到一串 ding

A 端的代码，前九行你们全见过：导入、参数、按钮、连 WiFi、连云。

只有最后四行是今天的。

if button.value() == 0: —— 按钮按下读到 0。

为什么是 0 不是 1？——（等答）上拉。第4课就讲过的老朋友，PULL_UP。

按下了，就 client.publish(TOPIC, "ding")。

（重点）

注意 publish 的两个东西：往哪个柜子放、放什么话。

主题是 g1g2door01，话是 "ding"——一个字符串，不是字节。

这是巴法云的脾气，L18 校准过：传字符串。

最后那个 time.sleep(0.5)，黑条上写了，叫「防连发」。

为什么要防？

（停顿）

因为你的手指按一下，其实抖了好几次。

这段循环 0.05 秒转一圈，你按住半秒，它能发出十条 ding。

对面那块板就会疯掉。

加了这 0.5 秒，按一下就是一条。

起步全码 · B 端（接收板）
WIFI_SSID="你的WiFi名"; WIFI_PASS="你的WiFi密码"; KEY_B="B板私钥"
TOPIC = "g1g2door01"        # 和 A 端一模一样
led = Pin(2, Pin.OUT)
def message_callback(topic, msg):
    if msg.decode() == "ding":
        led.value(1); time.sleep(3); led.value(0)
client = MQTTClient(KEY_B, "mqtt.bemfa.com", 9501)
client.set_callback(message_callback)
client.connect(); client.subscribe(TOPIC)
while True: client.check_msg(); time.sleep(0.5)
