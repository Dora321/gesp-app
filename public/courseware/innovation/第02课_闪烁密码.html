第2课 参考代码 18–30 分

SOS 完整可运行代码

完整可跑 · SOS 循环播放
from machine import Pin
import time

led = Pin(2, Pin.OUT)

def blink(on_time, times):      # 闪 times 次，每次亮 on_time 秒
    for _ in range(times):
        led.value(1)
        time.sleep(on_time)
        led.value(0)
        time.sleep(0.2)

while True:
    blink(0.2, 3)               # S：三短
    time.sleep(0.6)
    blink(0.6, 3)               # O：三长
    time.sleep(0.6)
    blink(0.2, 3)               # S：三短
    time.sleep(2)               # 播完停 2 秒，循环

这就是 AI 第二次给的完整代码，能直接跑。

我先说清楚：这段里有两个你们还没学过的东西——def 和 for。今天不要求你们看懂它们，进阶组照着用就行。

你们今天要看懂的是下面 while True 这一段：blink 0.2 三次，停 0.6；blink 0.6 三次，停 0.6；blink 0.2 三次，停 2 秒。

念出来是不是就是——三短、三长、三短、停？

代码和你刚才拍的手，是一一对应的。

上面那个 def blink，你可以把它理解成「我给『闪几下』这个动作起了个名字」，以后写 blink(0.2, 3) 就等于「亮 0.2 秒闪三下」。

现在看得懂大概意思就够了。基础组待会儿不用写这段，有更简单的起步代码。

今天只有两个新东西，我们一个一个读。

第一个，while True:。我给它起个外号，叫「不会累的跑步机」。只要你站在它上面，就会一直跑下去，永远不停。

注意看它后面跟着的小尾巴——缩进！下面那几行都往右退了一格。

凡是缩进的代码，都在跑步机上，会被一直重复。顶格写的就不在跑步机上，只跑一次。

这个缩进特别重要，待会儿有一半的报错都是因为它。

第二个新东西，time.sleep(1)——让板子「睡」1 秒。睡着的时候干什么？什么都不干，所以灯保持原样。

灯亮着的时候睡 1 秒，就是亮 1 秒；灯灭着的时候睡 1 秒，就是灭 1 秒。

所以——控制闪得快还是慢的，就是这两个数字。把 1 改成 0.1，会怎么样？待会儿你们自己试。

这一页是今天最容易踩的坑，看仔细。

上面这条：while True: 写完，换行向右退一格，再写 led.value(1)。这样这行就在跑步机上，会被一直重复——灯就不停地闪。

下面这条：while True: 写完，换行顶格写。这样它就不在跑步机上了。

结果不是「只闪一次」，而是——直接报错。红字：IndentationError。

Indentation 这个英文词就是「缩进」的意思。所以你们以后在报错里看到这个词，不用全看懂，就知道一件事：我的缩进不对。

怎么退这一格？按 Tab 键，或者敲四个空格。PyCharm 一般会帮你自动退，但你要看一眼它退了没有。

第2课 集体 Debug 75–85 分

报错了怎么办？三个高频错

红字不可怕，它在告诉你哪儿写错了

IndentationError

缩进错了——while True: 下面那几行忘了往右退一格，或者退得不齐。

SyntaxError

语法错了——多半是 while True 后面的冒号忘了，或者 while 写成了大写 While。

NameError: time

忘了 import time——第二行补上 import time 就好。

灯一直亮 / 一直灭不闪？检查 value(1) 和 value(0) 之间是不是都有 sleep

我看到好几组屏幕上有红字，都停一下，一起看这三个。

第一个，IndentationError。刚才讲过，缩进的意思。while True 下面忘了退一格，或者几行退得不一样齐。对照缩进图自己改。

第二个，SyntaxError。语法错。今天最常见的就两种：while True 后面那个冒号忘了；或者把 while 写成了大写的 While——Python 认小写。

第三个，NameError，后面跟着 time。这是说「我不认识 time 这个东西」——因为你忘了第二行 import time。补上就好。

还有一种不报错但不对的：灯一直亮着，或者一直灭着，就是不闪。查什么？查 value(1) 和 value(0) 中间是不是都有 sleep。少一个，灯切换得太快，你的眼睛看不出来，就像一直亮着。

红字不可怕。它不是在骂你，它是在告诉你哪儿写错了。
