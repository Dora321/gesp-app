第1课 逐行解读 18–30 分

3 行核心代码，逐行读

from machine import Pin
=
从 ESP32 的「大脑」里，拿出控制针脚的工具
led = Pin(2, Pin.OUT)
=
2 ＝ 针脚编号（板载 LED 焊在这儿）；OUT ＝ 输出，往外发信号
led.value(1)
=
1 就是开，0 就是关

这三行我们一行一行读。规矩是：我先问「你觉得这行在做什么」，你们先猜，猜完我再讲。

第 1 行，from machine import Pin。machine 是 ESP32 的大脑，Pin 就是板子边上那一排排针脚。这一行的意思是：从大脑里拿出控制针脚的工具。

第 2 行，led = Pin(2, Pin.OUT)。这里有两个关键。2 是针脚的编号——板载 LED 就焊在 2 号针脚上。OUT 是「输出」，意思是 ESP32 往外发信号。

那如果换成 IN 呢？那就是「输入」——听外面的信号，比如按钮。这个我们下下节课会用到。

第 3 行，led.value(1)。1 就是开，0 就是关。

就这三行。记住三个词：Pin 是引脚，OUT 是输出，value 是开关。

待会儿你们动手的时候，有个实验：把 Pin(2) 改成 Pin(4)，再上传。

灯会不亮。我现在先问一句：代码错了吗？

（等他们答）

代码没有错。它确实老老实实往 4 号针脚发了「开」的信号。

看这张图。上面这条线：Pin(2) → GPIO2 → 这里焊着板载 LED → 所以灯亮。

下面这条线：Pin(4) → GPIO4 → 那里什么都没接 → 所以灯不亮。

问题不在代码，在代码和硬件对不上。

这是今天最重要的一个道理，它叫软硬件映射：代码里写的引脚号，必须和真实世界里元件接的位置对上。

所以以后你们问 AI 写代码，一定要告诉它：我的元件接在哪个针脚。不然 AI 写的代码再漂亮，也点不亮你的灯。
