第17课 第①步 8–20 分

连上 WiFi

语言MicroPython
硬件ESP32
接线无需接线（用板载 WiFi）
效果连接 WiFi（名字 XXX，密码 XXX），成功后打印 IP
约束只用 network、ntptime、time，加中文注释
五要素问 AI：「我用 MicroPython，硬件是 ESP32。请写代码：连接 WiFi（名字 XXX，密码 XXX），连接成功后打印 IP；再用 ntptime 校时，按北京时间（+8小时）每秒打印当前时间。约束：只用 network、ntptime、time，加中文注释。」
起步全码 · 第①步：连上 WiFi
import network, ntptime, time

WIFI_SSID = "你的WiFi名"
WIFI_PASS = "你的WiFi密码"

# 第①步：连 WiFi
wlan = network.WLAN(network.STA_IF)
wlan.active(True)
wlan.connect(WIFI_SSID, WIFI_PASS)
while not wlan.isconnected():
    time.sleep(0.5)
print("已联网，IP =", wlan.ifconfig()[0])

联网代码看着长，但核心只有两行，我先讲这两行。

wlan = network.WLAN(network.STA_IF) —— 这行是「装上网卡」。

就像给板子插了一块网卡。STA_IF 的意思是「我当客户端，去连别人的热点」，而不是自己当热点。

wlan.connect(名字, 密码) —— 这行是「输 WiFi 密码」。

和你在手机上点一下热点、输密码，是完全一样的事。

剩下的呢？

wlan.active(True) 是「把网卡打开」。

那个 while not wlan.isconnected() 循环是「等它连上」——连不上就每半秒查一次。为什么要等？因为连 WiFi 要几秒钟，不等就往下跑，后面全错。

最后 print("已联网，IP =", ...) —— 这是成功的标志。

看到 IP 地址打印出来，就算连上了。 这是今天的第一个里程碑。

现在照五要素向 AI 要代码，验收三查之后再上板。

连不上是常态，不是意外。所以我给你们一张连网三查卡。

规矩只有一条：一次只查一样。一起改三样，你永远不知道是哪样的问题。

①查名字。 热点名一个字母、大小写都不能错。WiFi 名里的空格、下划线、中英文，都要一模一样。

②查密码。 重新手动输一遍，别用输入法联想——联想出来的可能带了个空格。

③查网络。 教师热点开了吗？还有最关键的——是 2.4GHz 吗？

ESP32 不认 5G 热点。 这是每年最常见的一条。手机开热点的时候，设置里要选 2.4GHz 或者「兼容模式」。

三查都过还连不上？举手换 B 路径模板。 先把网上了，课后再查原因。

还有一个现象要会认：串口一直卡着不打印 IP。

那不是死机，是还在 while 里等——说明没连上。看到这个现象，直接进三查。

第17课 第②步 50–65 分

向云问时间

接在第①步后面，合起来就是完整程序

起步全码 · 第②步：NTP 校时
# 第②步：NTP 校时（接在上面后面）
ntptime.settime()          # 云给的是世界时
while True:
    t = time.localtime(time.time() + 8*3600)
    print("现在 %02d:%02d:%02d" % (t[3], t[4], t[5]))
    time.sleep(1)
云给的是世界时，中国要 +8 小时 ＝ + 8*3600 秒——忘了这个，时间就差 8 小时

揭晓答案。板子怎么知道几点？

它去问云。

就一行：ntptime.settime()。

NTP 是「网络时间协议」的缩写。这一行的意思是：向网上的时间服务器问一句「现在几点」，然后把自己的表对准。

你想想这有多神奇：一块从来不知道时间的板子，联网一秒钟，就知道现在几点几分几秒了——准到秒。

它不需要时钟芯片，因为网上有人替它记着。

这就是上节课说的「云」：设备问，云答。

下面有个坑，黑条上写了，这是今天最经典的参数错：

云给的是世界时（UTC）。 中国在东八区，要加 8 小时。

8 小时是多少秒？8 × 3600。所以代码里写 time.time() + 8*3600。

忘了加？你的板子会报伦敦时间——比我们晚 8 小时。

待会儿谁的时间对不上，先查这一处。

今天三个发现。

第一个，联网只有两行核心：装上网卡、输密码。

剩下那些 while 等待、打印 IP，都是围着这两行转的。以后你看到任何联网代码，先找这两行，别被长度吓住。

第二个，也是今天最神奇的：设备能向云「问」东西。

没有时钟芯片，照样知道现在几点。这句话我想让你们琢磨一下——

第三个，连不上是常态。按三查排，一次只查一样。这不是丢人的事，是每个工程师每天都在做的事。
